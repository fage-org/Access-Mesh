**小计：6 个模块**

### 各模块讨论要点

**G-1 过滤器链设计**

- RequestIdFilter：追踪 ID 格式（UUID / Snowflake），是否对接 SkyWalking/Zipkin
- HeaderCleanFilter：清洗头列表是否完备，是否需要自定义扩展点
- WhitelistFilter：白名单路径匹配规则（精确 / Ant / 正则），配置热更新方式
- AuthTokenFilter：Token 解析失败时的策略（返回 401 / 放行标记匿名），多端 Token 区分
- PermissionFilter：L1 Caffeine 缓存大小 / TTL 是否合理，缓存失效策略，权限快照格式
- HeaderEnrichFilter：注入头的字段列表是否足够（userId / tenantId / userName / roles 等）

**G-2 路由配置**

- Nacos 路由配置的 DataId / Group 命名规范
- 路由匹配优先级规则
- StripPrefix 策略与各服务路径前缀的对应关系
- serviceCode 映射机制与权限中心的一致性保障

**G-3 异常处理**

- 统一响应格式是否需要扩展字段（timestamp / path）
- 各错误码对应的 HTTP Status Code 映射
- 下游服务异常（502/504）时是否返回原始错误信息
- 全局异常处理器与过滤器异常的统一收口

**G-4 配置结构**

- bootstrap.yml vs Nacos 配置拆分策略
- 敏感配置加密方式（Redis 密码、Sa-Token 密钥）
- 配置变更热更新机制

**G-5 权限中心交互**

- 接口快照格式与数据量评估
- 版本号比对的 Redis Key 设计
- 权限中心不可用时的降级策略（使用本地缓存 / 全部拒绝 / 全部放行）

**G-6 安全设计**

- HTTPS 终端层级（Gateway 做 TLS / 前置 Nginx 做）
- Token 在日志中的脱敏规则
- 请求体大小限制默认值
- 是否需要 CORS 配置

**小计：11 个模块，75 个接口，17 张表**

### 各模块讨论要点

**A-1 认证模块**

- OAuth2 客户端管理接口的入参/出参结构
- 密码/短信/授权码三种登录流程的详细时序
- 验证码实现方式（图片验证码生成库、短信验证码服务商对接）
- 密码错误锁定规则（次数/时间窗口/锁定时长的默认值）
- 单设备登录策略的实现（Sa-Token 的 kickout 机制）
- 异地登录检测的 IP 归属地查询方案
- Token 刷新的滑动窗口机制
- 登录日志存储与清理策略

**A-2 用户管理**

- sys_user 表 extra JSONB 字段的约定结构（扩展方如何规范使用）
- 用户同步到权限中心的时机（创建/更新/禁用/删除）
- API + MQ 双通道同步的一致性保障和失败重试
- 用户导入/导出的文件格式和字段映射
- 密码初始化和重置策略

**A-3 组织管理**

- 统一组织模型（DEPT/POSITION/TEAM 同表 org_type 区分）的查询性能
- 多棵组织树的根节点管理规则
- 一人多岗位的关联结构
- 组织同步到权限中心 abstract_role(ORG 类型) 的映射规则
- 组织删除/合并时的级联处理

**A-4 菜单管理**

- 菜单树深度限制
- 菜单与权限中心 resource_entity(MENU/BUTTON) 的同步时机
- 菜单排序规则（同级排序字段）
- 前端路由组件的 component 字段约定（路径格式/Layout 组件）
- 外链菜单和内嵌 iframe 的处理

**A-5 角色管理**

- 代理权限中心的接口列表（哪些直接透传、哪些做聚合）
- 角色与组织的关联规则
- 角色分配用户的界面交互设计
- 权限中心返回数据到管理服务前端的适配层

**A-6 字典管理**

- 字典类型的命名规范（sys\_ 前缀 / 业务前缀）
- 字典值的数据结构（label/value/cssClass/listClass）
- Redis 缓存的 Key 设计和更新策略
- 内置字典（不可删除）标识机制

**A-7 通知管理**

- 公告类型分类（通知/公告）
- 站内信投递目标（全员/部门/角色/指定用户）
- 已读状态的存储方式（独立表 / 位图）
- 消息推送通道（WebSocket / SSE / 轮询）

**A-8 文件管理**

- S3 兼容存储的配置模型（多存储实例支持）
- 文件上传大小限制和类型白名单
- 文件名策略（原名 / UUID / 日期路径）
- 缩略图/预览的支持范围

**A-9 审计日志**

- AOP 日志注解的参数设计（模块/操作类型/描述模板）
- 日志记录的字段列表（操作人/IP/请求参数/响应结果/耗时）
- 敏感参数脱敏规则（密码/Token 等字段）
- 日志保留策略和归档/清理

**A-10 任务调度**

- Spring Scheduler vs Quartz 的选择理由
- 任务定义的存储（数据库配置 / 代码硬编码）
- 集群环境下任务去重（分布式锁方案）
- 任务执行日志和失败告警
- Cron 表达式校验
- 手动执行/暂停/恢复接口

**A-11 系统设置**

- 配置项的层级（全局默认 → 租户级覆盖）
- 预置配置项列表（密码策略、登录策略、文件策略等）
- 配置变更的生效方式（即时 / 重启）
- 配置项值的数据类型（STRING/NUMBER/BOOLEAN/JSON）

## 五、讨论方式

每个模块讨论时将覆盖：

- 接口设计是否合理（入参/出参/命名）
- 业务规则是否完整
- 边界情况和异常处理
- 与其他模块/服务的交互依赖
- 性能考量
- 演示效果（Example 模块特有）
