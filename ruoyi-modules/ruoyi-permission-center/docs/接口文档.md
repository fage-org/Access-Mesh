# 权限中心（Permission-Center）接口文档

本文档面向前端联调，给出每个接口的 URL、方法、请求体与响应体字段说明。所有接口均需携带项目统一 Token（如 Header `Authorization`），与若依网关一致。

---

## 1. 通用说明

### 1.1 Base URL

- 前端请求基址：**`/permission-center`**（相对网关地址）。
- 接口路径前缀：**`/api/perm`**。
- 示例：`POST /permission-center/api/perm/resources/list`。

### 1.2 请求与响应约定

- **请求**：均为 **POST**，`Content-Type: application/json`，Body 为 JSON。
- **成功列表（非分页）**：`R<List<T>>` → `{ "code": 200, "msg": "操作成功", "data": [ ... ] }`。
- **分页**：`TableDataInfo<T>` → `{ "code": 200, "msg": "查询成功", "rows": [ ... ], "total": 100 }`。
- **无体**：`R<Void>` → `{ "code": 200, "msg": "操作成功", "data": null }`。
- **失败**：`code` 非 200，`msg` 为错误说明。

### 1.3 通用请求体 IdsReq（批量删除）

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| tenantId | Long | 是 | 租户ID |
| ids | List\<Long\> | 是 | 主键列表，单次最多 100 条 |

## 10. 鉴权（PermissionCheck）

**基础路径**：`/api/perm`

| 接口路径 | 方法 | 请求体 | 响应体 | 说明 |
|----------|------|--------|--------|------|
| /check | POST | PermissionCheckReq | R\<PermissionCheckVo\> | 单次鉴权 |

> Phase 5 对齐说明：
> 本接口按 `plan/PHASE0_API_CONTRACT.md` 执行。
> 请求字段使用 `userId`，当前语义对应 `abstract_user_id`。
> 为兼容历史调用，仍接受旧字段 `abstractUserId`，但不再作为对外标准字段。
> 响应字段使用 `granted` / `denyReason`，不再使用旧字段 `allowed` / `reason`。
> 更完整说明见 `docs/PHASE5_PERMISSION_CHECK_CONTRACT.md`。

**PermissionCheckReq**

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| tenantId | Long | 是 | 租户ID |
| userId | Long | 是 | 用户ID，当前语义对应 `abstract_user_id` |
| resourceEntityId | Long | 是 | 资源ID |
| operationPermissionId | Long | 是 | 操作权限ID |
| bizDomainId | Long | 否 | 传入则只考虑该域内或该域绑定的全局角色 |
| inheritMode | String | 否 | `NONE` / `CHILDREN` / `PARENT` / `BOTH`，默认 `NONE` |
| checkDependency | Boolean | 否 | 是否同时校验依赖链，默认 `false` |
| context | Map\<String, Object\> | 否 | 供条件 handler / 自定义表达式使用 |

**PermissionCheckVo**

| 字段名 | 类型 | 说明 |
|--------|------|------|
| granted | Boolean | 是否允许 |
| denyReason | String | 拒绝原因：`NO_ROLE` / `NO_PERMISSION` / `CONDITION_FAIL` / `CONFLICT` / `DEPENDENCY_FAIL` |
| grantedBy | Array | 命中的授权来源 |
| conflicts | Array | 冲突明细 |
| dependencyGaps | Array | 依赖缺口 |
