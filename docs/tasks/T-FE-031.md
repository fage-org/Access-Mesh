# T-FE-031 中栏直接操作矩阵+单元格聚合摘要+分支列表就地展开

## 目标

实现中栏直接操作矩阵与单元格聚合摘要，分支列表就地展开（非弹窗）。

## 非目标

- 不实现批量工具栏（T-FE-032）。
- 不实现子权限矩阵（T-FE-033）。

## 实现要点

- `PermissionMatrixPanel`（V2 独立组件，不复用旧 `RePermissionCell`）。
- `BranchListPanel` 就地展开行（每分支按 GrantVariantId 操作）。
- 动效遵循 `prefers-reduced-motion`。

## 验收标准

以 frontmatter `acceptance` 为准。
