# T-GW-003 stale-allow 实现

> 来源：[gateway-fail-mode-plan](../plans/gateway-fail-mode-plan.md) 任务 C-3（工作单 C，方案 C1+C2）

## 依赖说明

- **T-PERM-001**：stale-allow 依赖 InterfaceSnapshot 缓存对象（Boolean 无所谓"过期但未驱逐"，快照可以）。快照模式未落地则本任务无法实现。
- **T-GW-001**：fail-mode 配置项与 stale-grace-seconds 阈值。

## 待设计耦合

T-GW-005（S-006 设计 ✅ 已完成）已定义三层缓存结构（主缓存 + stale store + invalidatedKeys）和 stale-allow 续命契约。本任务按该规范实现：
- 主缓存 `RemovalListener`（cause=EXPIRED）→ 写入 stale store（`StaleEntry` 含 `staleUntil`）
- stale-allow 续命：从 stale store 取出 → 检查 `staleUntil` + `!invalidatedKeys.contains(key)`
- `perm:invalidate` 事件：同时驱逐主缓存 + stale store + 标记 invalidatedKeys

## 设计回写

- `docs/design/services/gateway.md`：补"fail-mode 三模 + stale-allow 续命"段落
