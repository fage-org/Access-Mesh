## 已知差距（联调发现，登记不修）

- **XML+Page 参数不生效族（T-ADMIN-026 登记）**：9 个 XML 映射 mapper 方法以 flex `Page` 作参数/返回值，有行即 ClassCastException 500（paginateByCondition 冒烟实证）；当前无 UI 消费页，属 T-FE-015 同族遗留。
- **PgIT stringtype 追加无效（T-ADMIN-026 一并登记）**：Testcontainers getJdbcUrl() 自带查询参数，既有 PgIT 直接 `+ "?stringtype=unspecified"` 实为并入前一参数值被 pgjdbc 静默忽略；现有断言均走显式 setObject 不受影响，KeywordLikeSearchPgIT 已用分隔符判断修正。
- **user-role assign 无变更日志**：revoke 路径写 USER_ROLE_CHANGE（聚合行 BATCH_REMOVE + diff items）而 assign 路径只写 operation_log 不写 permission_change_log——审计不对称，影响 §6.8 USER_ROLE_CHANGE 历史半缺与排查页保留口径；聚合粒度（单行 BATCH_INSERT vs 逐行 INSERT）属设计决策待定。
