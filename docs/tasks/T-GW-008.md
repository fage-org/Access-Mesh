# T-GW-008 Gateway XFF 清洗与客户端 IP 重建

> 状态：proposed（2026-09-10 codex luna max 外评 T-PERM-057 的 P1，用户三选一定案「Gateway 清洗+重建」，独立立项不塞入 T-PERM-057；定案登记 decision-registry 2026-09-10）。

## 背景

codex 外评发现：客户端可伪造 `X-Forwarded-For` 绕过 IP 白名单/黑名单条件——Gateway `HeaderCleanFilter` 清洗列表不含 XFF/X-Real-IP（伪造值原样透传），而 access-service `HttpRequestUtils.getClientIp` 与 Gateway `PermissionFilter.resolveClientIp`（快照条件重评，T-PERM-017 起存量）均优先采信 XFF 首段。T-PERM-057 管理面写门禁条件评估拉平后，该信任面扩大到写操作判定，成为现实攻击面（持合法凭证 + 伪造 XFF = IP 条件失效）。

## 范围

- Gateway：清洗列表 + IP 重建（remoteAddr 单一可信来源写回 XFF）。
- 回归锁与部署前提文档（security-standards/runbook 多层 LB 说明）。
- access-service 侧无代码改动（消费链不变，输入变为可信重建值）。

## 非目标 / 遗留

- 可信代理链解析（trusted-proxies 多跳精确采信）——定案弃（见 registry）。
