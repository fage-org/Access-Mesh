# T-GW-008 Gateway XFF 清洗与客户端 IP 重建

> 状态：done（2026-09-10 收口；全量回归 -T 1C 含 E2E 全绿；双轨评审处置完毕——两项 P2/三项 P3 直接修复、三项用户拍板落实，见 decision-registry 同日「T-GW-008 实施定案与存量缺陷修正」行）。

## 背景

codex 外评发现：客户端可伪造 `X-Forwarded-For` 绕过 IP 白名单/黑名单条件——Gateway `HeaderCleanFilter` 清洗列表不含 XFF/X-Real-IP（伪造值原样透传），而 access-service `HttpRequestUtils.getClientIp` 与 Gateway `PermissionFilter.resolveClientIp`（快照条件重评，T-PERM-017 起存量）均优先采信 XFF 首段。T-PERM-057 管理面写门禁条件评估拉平后，该信任面扩大到写操作判定，成为现实攻击面（持合法凭证 + 伪造 XFF = IP 条件失效）。

## 范围

- Gateway：清洗列表 + IP 重建（remoteAddr 单一可信来源写回 XFF）。
- 回归锁与部署前提文档（security-standards/runbook 多层 LB 说明）。
- access-service 侧无代码改动（消费链不变，输入变为可信重建值）。

## 非目标 / 遗留

- 可信代理链解析（trusted-proxies 多跳精确采信）——定案弃（见 registry）。

## 实现记录（2026-09-10）

> 执行期两项用户拍板（resolveClientIp 直用 remoteAddr；回归锁钉 Gateway 单测不进 e2e）与两项存量缺陷修正（大小写变体绕过、putAll 叠加语义）已登记 decision-registry 2026-09-10「T-GW-008 实施定案与存量缺陷修正」行；本节只记终态。

**终态实现**：

- `GatewayProperties.header.clean` 默认列表 + `application.yml` 同步加 `X-Forwarded-For` / `X-Real-IP`（yml 含误删警示注释——误删 XFF 项时正常路径仍被无条件 set 覆盖（仅 remoteAddr 不可得分支透传外部值）、误删 X-Real-IP 项时外部值透传但 access-service 无消费方，各项均勿移除）；另扩列 `X-Forwarded-Host/Port/Proto/Prefix` 与 `Forwarded`（用户拍板一并清洗——同属外部可伪造转发声明，当前三服务零消费，防未来 `forward-headers-strategy` 开启时伪造面复活）。
- `HeaderCleanFilter`：显式 `h.remove(cleaned)` 清洗（HttpHeaders 底层大小写不敏感，任意变体一并删除）+ `h.set("X-Forwarded-For", remoteAddr)` 重建写回（set=替换，配置误删时外部任意值/多值也被覆盖为单值观测值）；remoteAddr 不可得不写回，下游按自身 remoteAddr 兜底。**实现约束**：不得走「构建干净头副本再 putAll」——`ServerHttpRequest.Builder#headers` 的 consumer 收到的是原请求头的可写视图，putAll 为叠加语义、清洗项不会被移除（归并起旧实现即因此从未真正删除过头，仅靠下游注入 filter 的 set 覆盖兜底；本任务实测修正并以回归锁钉住）。
- `PermissionFilter.resolveClientIp`：直用 socket 层 remoteAddr，不读任何请求头（单一可信来源；清洗配置误删不复活伪造面）。
- `application.yml` 置 `spring.cloud.gateway.x-forwarded.for-append: false`（用户拍板）：SCG 内置 XForwardedHeadersFilter 默认在代理出口再追加一段同值致下游 XFF 双段冗余，关闭改替换写回——文档/单测/生产三者单值形态一致；host/port/proto/prefix 维度维持 SCG 默认 append（写入网关观测真实值）。
- access-service 侧零行为改动（消费链与测试面零影响，仅 javadoc/文档口径同步三处：PermEvalContext clientIp 注释「透传」改「重建」、HttpRequestUtils.getClientIp 注释补 Gateway 重建前提、architecture §8.2 两句补重建括注——用户拍板注释级触达）。

**回归锁**（`HeaderCleanFilterTest`，MockServerWebExchange 风格，chain 内捕获下游最终 request 断言）：直连无 XFF（重建单值）/ 经代理伪造 XFF 链（不透传）/ 小写变体伪造（变体缝隙）/ X-Real-IP 删除（含变体）/ 内部头小写变体（存量 clean 列表同缝隙）/ 无关头透传不受波及 / remoteAddr 不可得不写回。`PermissionFilterMetricsTest` 适配：buildExchange 由 `X-Real-IP` 头改设 remoteAddress。

**文档回写**：`gateway.md` 新增 §请求头清洗与客户端 IP 重建（含实现约束与多层 LB 部署前提）+ §快照模式鉴权 clientIp 提取顺序句改写 + 核心链路第 3 条；`security-standards.md` 新增 §7 客户端 IP 信任面（含「记住」行）；`rebuild-runbook.md` §3 加前置代理拓扑部署前提行。
