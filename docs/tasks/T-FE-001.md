# T-FE-001 跨页组件抽象池

> 状态：proposed
> 作用：维护 Phase 1 跨页组件抽象池清单，在页面推进到 2+ 复用时派生子任务。不直接实现组件。

## 背景

improvement-plan §4.1 Step 1.5 要求可复用组件抽取必须先与用户确认。本任务作为清单维护中枢，避免每个页面任务内嵌组件决策。ReOrgTreePanel 已在 2.1 确认并实现，不纳入。

## 候选清单

见 `docs/plans/frontend-phase1-plan.md` §跨页组件抽象池。当前 4 个待确认候选：
- 权限条件选择器（T-FE-009 / T-FE-014 推进时确认）
- 资源树选择器（T-FE-008 / T-FE-013 / T-FE-014）
- 角色选择器（T-FE-002 已识别父角色选择器内联实现 / T-FE-014 推进时确认抽取）
- Diff 对比面板（T-FE-005 / T-FE-012）

## 工作方式

1. 各页面任务（T-FE-002~014）在 Step 1.5 识别可复用组件时，回写本任务的清单确认状态
2. 当某候选在 2+ 页面确认复用时，本任务派生独立 T-FE 子任务实现该组件
3. 派生的组件任务被相关页面任务 depends_on

## 验收标准

- 清单确认状态与各页面任务实际推进一致
- 派生的组件任务命名遵循 Re 前缀
- 不在未达 2+ 页面时提前抽取
