# T-FE-034 保存前总览+失败两子态+STALE_WITH_CHILD_FAILURE+fetchBaseline+离开保护

## 目标

实现保存前总览、失败两子态恢复、fetchBaseline 原子恢复、离开保护。

## 非目标

- 不实现 mock 与回归（T-FE-035）。

## 实现要点

- hook 拆 `reloadBaseline`（普通保存成功后刷新，清草稿）与 `fetchBaseline`（不清草稿，用于 reconcile）。
- saveAll 返回 Promise<boolean>，区分"未开始"与"开始后失败"。
- SAVE_PREVIEW sheet 失败视图按子态呈现可恢复动作。

## 验收标准

以 frontmatter `acceptance` 为准。
