# T-FE-014 4.1 权限授予页

> 状态：done
> 复杂度：🔴 高（第 3 批，核心页）
> 后端任务：T-PERM-034（depends_on 本任务）

## 背景

权限授予页（核心）：选角色→勾资源树→配操作矩阵→绑条件（可内联新建）、批量保存、子权限/范围权限、自动授权预览。布局：三步向导 or 分栏配置。

## 后端契约锚点

- `api-contract.md §5.5`（L241，`role-resource-permission/*`）
- `api-contract.md §6.4`（L935，三段式角色授权 save）
- `api-contract.md §6.5`（L985，子权限/范围权限 add-child/children）
- `implementation.md §4` 权限授权管理模块（§4.2 批量授权执行链路 L429）+ `§2.8` PermissionGrantDomainService

## 组件候选（3 个）

- 资源树选择器（本页 + 3.1 资源管理 + 4.2 权限查询）
- 角色选择器（本页 + 2.2 角色管理）
- 权限条件选择器（本页内联新建 + 3.2 条件管理独立 CRUD）

均登记 T-FE-001 组件池，2+ 页确认后抽取。

## 注意

- 自动授权预览依赖 Phase 2 T-PERM-035（design-review §11 E4 暂缓），P0 标 TODO 不实现。
- **可授予角色范围**：选角色时应能选到全部 5 种类型（BASIC_ROLE / GROUP_ROLE / PERSONAL / ORG / POSITION）——后三类由外部同步生成、不在角色管理页 CRUD，但需在此页分配权限（评审反馈 2026-06-30 确认，B 选项 3）。
- **PERSONAL 权限分配入口**（评审反馈 2026-06-30 B 选项 3）：除本页外，2.1 用户详情页需弹额外窗口配置该用户 PERSONAL 角色的权限（弹窗形式避免页面杂乱）。本任务只负责 4.1 页内选 PERSONAL 授权；2.1 用户详情弹窗属 T-FE-015/2.1 页面改造，登记待后续推进。
