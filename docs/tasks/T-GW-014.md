## 背景

P1。外部持续审查发现（2026-10-14 主代理核实成立）：`gateway/.../filter/InternalSecretFilter.java:45-64` 仅按「配置非空、请求没有凭证头」决定注入 `X-Internal-Secret`，未按目的服务收窄；`gateway/src/main/resources/application.yml` 含 example-service 真实路由，普通用户请求经 Gateway 访问业务接口时，业务服务可从请求头读到平台内部共享密钥。T-ACCESS-079/080 后外部业务已切 per-service 凭证，但仅移除业务侧配置无法完成回收——业务进程仍通过普通用户流量获得新密钥，轮换后又会收到新值；`RequestContextInterceptor.java:192-209` 的内部无自报查询通道消费该头，泄漏面扩大到平台内部查询信任域。

## 范围

InternalSecretFilter 注入条件收窄到目的服务；Gateway 内部查询显式凭证路径保持；部署文档中内部密钥的归属与回收描述同步。

## 当前口径

仅对实际路由目的为 access-service 的请求注入；业务下游的用户身份继续用现有签名机制。不取消 Gateway→access-service 内部互信，不新增每内部调用一套凭证体系。T-PERM-070 时代的「无凭证头兜底注入」描述按本卡收窄语义改写。

## 验收对照

见 frontmatter `acceptance`；测试须包含「同一入口、不同路由目的」的差异断言（旧实现下失败）。

## 非目标 / 遗留

不重提运行时 TLS 检测（服务认证 §3.2 启动声明式护栏是已接受边界）；不改造 per-service 凭证协议本身。

## 完成记录

- 实现（2026-10-14）：`InternalSecretFilter` 注入条件在「配置非空 + 无凭证头」之上增加目的收窄——仅实际路由目的为 access-service（判据=路由 URI host，与 route id 无关）才注入；路由属性缺失 fail-closed 不注入。`PermissionClient` 直连通道（显式带密，不经本过滤器）保持可用；白名单路径均路由目的 access-service，兜底注入不受影响。
- 回归锁：新增 `InternalSecretFilterRouteNarrowingTest`（四用例：access-service 目的注入 / 同入口 example-service 目的不注入 / 路由属性缺失不注入 / 判据=URI host 而非 route id）；既有 `InternalSecretFilterCredentialNarrowingTest` 适配为固定 access-service 路由目的（凭证维度与路由维度分册锁）。
- 红跑实证：新锁在旧实现下 `mvn test -pl gateway -Dtest=InternalSecretFilterRouteNarrowingTest` → Tests run: 4, Failures: 2（`shouldNotInject_whenRoutedToOtherDownstream` 与 `shouldNotInject_whenRouteAttributeMissing` 均 expected: null but was: "internal-secret-value"）；实现后两类合计 7/7 绿。
- 回归（2026-10-14）：`mvn test -pl gateway` → 145 项 0 失败；`mvn test -pl e2e -am -T 1C -DskipTestcontainers=true -DskipHeavyIT=true` → BUILD SUCCESS（reactor 全模块 0 失败，含 gateway 145、access-service 1872〔单测轨〕、e2e 33——真实网关路由下 access-service 与 example-service 双目的流量全过）。
- 设计回写（四册 last_reviewed 已 bump）：service-authentication.md §3.2 信任表③与 §3.3 经 Gateway 行、gateway.md InternalSecretFilter 收窄段与部署约束段、契约总册 §24 经 Gateway 行、deployment.md §服务凭证接入与内部密钥轮换；`gateway/application.yml` 内部密钥注释同步目的收窄语义；T-PERM-070「无凭证头即兜底注入」口径按取代关系改写。
- 双轨评审：代码轨 P3×1（过滤器内旧口径残留注释「无凭证头才兜底注入」）直修；文档轨零发现；无过度设计可裁剪项、无存疑待决策项。
