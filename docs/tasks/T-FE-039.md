# T-FE-039 矩阵图标正交状态模型与图标精简

> 状态：done（2026-08-07 实现完成。2026-08-05 二轮评审映射定稿：条纹=条件/粗黑边框=canGrant/红·淡红=撤销，取代上轮'条纹=部分移除/粗黑边框=整格删除'映射；双重继承图标与子权限分叉此前已确认；**2026-08-06 三轮评审定稿：多来源聚合归并规则 + AUTO_DEP 详情层表达（不占独立图标位），'授权来源视觉表达'待定状态解除；四轮评审修正：AUTO_DEP 仍作为有效来源参与聚合计算（仅 AUTO_DEP 显示普通有效图标、撤销 MANUAL 后 AUTO_DEP 有效图标+红撤销并列、只读落实到记录级不禁用单元格）**）
> 依赖：T-FE-038（单类型矩阵上下文基线，图标模型在其上收敛）
> 前置验收：见 acceptance

## 背景

权限授予矩阵的单元格状态（直接/资源继承/操作继承/双重继承/条件/可授予/ALL/多分支/AUTO_DEP/变更态）此前以增量角标（C/G/A/⧉/＋/−/⧄/删除线）表达，图标数量随状态增长且无正交约束。**2026-08-05 二轮评审映射定稿**：条纹=有条件、粗黑边框=可转授 canGrant、红/淡红=撤销、红白/淡红白条纹=撤销来源有条件；撤销用"有效图标+撤销图标并列 / 只显示撤销图标"表达，**不再使用减号、删除线或"粗黑边框=删除"**。**2026-08-06 三轮评审定稿**：多来源聚合归并为单一聚合图标（正常态最多一个有效图标 + 撤销时最多再一个撤销图标，颜色/箭头/粗黑边框/条纹归并优先级见 §3.3）；AUTO_DEP 不再占独立图标位，仅在悬浮详情与只读交互中表达。**2026-08-06 四轮评审定稿**：AUTO_DEP 仍作为有效来源参与普通有效图标聚合（仅 AUTO_DEP 时显示普通有效权限图标，与 MANUAL 并存按全部来源归并）。

## 范围

1. §3.3 单元格状态表按二轮评审映射改写（条纹=条件、粗黑边框=canGrant、红/淡红=撤销、红白·淡红白条纹=撤销带条件、并列规则、禁用减号/删除线/边框=删除）。
2. §6.2 矩阵 diff 标记改写（add=绿、update=黄、remove=红/淡红/红白条纹 + 并列或仅撤销图标）。
3. 双重继承组合箭头与子权限分叉精确投影（仅直接主权限记录、继承格不复制、级联撤销附红图标）的实现。
4. **条件不可转授前端行为**（与 T-PERM-041 后端配套）：弹窗选条件清 canGrant、详情层编辑最终状态、20041 提示。
5. **多来源聚合归并（2026-08-06 三轮评审补）**：矩阵格正常态最多一个聚合有效图标、撤销时最多再一个撤销图标；颜色（任一直接->实色，全继承->淡色）、箭头（资源+操作继承不同记录->组合箭头）、粗黑边框（任一来源 canGrant=true）、条纹（全部有条件）归并规则（§3.3）。
6. **AUTO_DEP 参与聚合（2026-08-06 四轮评审修正）**：不占独立'授权来源图标'（撤虚线绿+自动补全图标），仍作为有效来源参与聚合计算（存在性/颜色/条纹/粗黑边框）；grantSource=AUTO_DEP 来源属性在悬浮详情标注；只读落实到记录/详情项（禁编辑/删除），不禁用整个单元格。
7. 验收场景（S2/S5/S6/S8/S10/S11）扩展与回归。
8. 设计回写 permission-grant.md §3.3/§6.2/§11。
