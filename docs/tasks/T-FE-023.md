# T-FE-023 扩展性验证 + 扩展指南

> 状态：in-progress（2026-09-12 批次启动：盘点完成 + 两项用户定案 + 指南草稿与容器用例产出，待用例跑绿与本卡收口）
> 原标题「SPI 策略扩展验证 + 扩展指南」；2026-09-12 盘点后重定调（见下）

## 重定调记录（2026-09-12 用户定案）

立项于 2026-06-29（improvement-plan §4.1 Phase 4），原设想三条验证线：SPI 策略扩展（条件评估、权限源）+ 配置驱动（数据权限维度、操作码定义）+ 代码级扩展（指南）。盘点结论：

| 原设想 | 2026-09 现状 |
|---|---|
| SPI 条件评估扩展 | **不存在**：条件操作符封闭 4 类（DATE_RANGE/TIME_RANGE/IP 白/黑名单），`ConditionEvalUtils` perm-common 静态实现，Gateway 与 access-service 共享，无扩展插槽 |
| SPI 权限源 | **概念已消亡**：统一引擎唯一事实源（role_perm_entry + 同事务投影，T-PERM-057） |
| 配置驱动 | **已成立且为产品主扩展面**：自有资源类型（类型级所有权 T-PERM-052 + 操作位按类型隔离 T-PERM-049）→ sync 通道 → 授权 → 判定；自有 subject_type/role_type 走 user/role sync 通道 |
| 代码级扩展指南 | 待产出；example-service 已演示接入形态；前端有固定页面扩展模式 |

两项用户定案（AskUserQuestion，2026-09-12）：

1. **指南定位 = 全景跨端**（A 选项）：落 `docs/design/extension-guide.md`，design_refs 随之调整；受众=接入方/二开者（服务接入 + 自有类型扩展 + 条件边界 + 前端页面扩展一章）。
2. **验证形态 = 补自有资源类型端到端用例**：容器组 `CustomResourceTypeSlicePgIT`（声明→操作定义→服务身份同步→授权→引擎判定 + 两条 fail-closed 负向）；另两场景（特殊判定逻辑边界、自有主体类型）文档级走查（指南 §4/§5/§6 承载）。
