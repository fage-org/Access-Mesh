# T-FE-038 权限授予页单类型矩阵上下文

> 状态：proposed（2026-08-03 单类型矩阵上下文定稿立项；T-FE-036 v3 页面为基线，本任务在其上增量改造）
> 依赖：T-FE-036（v3 页面基线，review 中）；**mock 先行，T-PERM-040 非前置**（与 T-FE-036/T-PERM-034 先例一致，联调任务 T-FE-018 同时依赖 T-FE-038 + T-PERM-040 成为真正汇合点，2026-08-05 评审方案 B）
> 前置验收：见 acceptance（需求 9 项 + 加载体验）

## 背景

v3 权限授予页（T-FE-036）矩阵以"各资源类型混合"呈现操作列。单类型矩阵上下文定稿：矩阵一次只呈现一个 `resourceTypeCode`，资源树、操作列、角色主权限记录、ALL 虚拟行、操作继承计算、操作列显示配置全部绑定当前类型。本任务为前端增量改造。

## 范围

1. 中栏工具栏新增资源类型下拉（候选 = **资源类型定义全集**（type-definition/list），目标主体已有权限类型仅标记/排序、不决定候选全集，防首次授权死锁，§2.2），驱动 MatrixContext。
2. 操作列加载改为 `operation-permission/list` 携带 `resourceTypeCode + includeGlobalFallback=true`（后端合并，前端不再自行实现专属优先/全局回退领域规则；mock 阶段按 §3.2 语义模拟）。
3. 操作列隐藏配置改为 `permission-grant:hidden-columns:{resourceTypeCode}`（按类型隔离），并清理已不存在操作码。
4. 来源链计算（source-chain.ts）操作继承只消费当前类型最终生效定义。
5. 类型切换加载流程（§3.6）：未保存变更确认 → 清空 → 并行查询 → 构建 → 骨架屏 → 请求序号丢弃旧响应。
6. 列表/资源树查询按当前类型过滤；`apply-grant-plan` 提交保持唯一写入口不变（20008 错误码映射接入既有错误码表）。
