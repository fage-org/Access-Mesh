# T-FE-032 授权交互（点击/添加分支/逐分支编辑撤销/批量新增分支）+ R11

## 目标

实现方案 A 分支级授权交互与 R11 重叠语义，批量与单项统一。

## 非目标

- 不实现子权限（T-FE-033）。
- 不实现保存流程（T-FE-034）。

## 实现要点

- commitGrantTask/replaceGrantTask/removeGrantTask 原子操作（沿用任务快照模型，但内部按 GrantVariantId）。
- validateTaskContext 防过期弹窗提交。
- 批量工具栏浮出 sticky。
