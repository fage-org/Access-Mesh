# T-FE-065 管理界面补齐

## 背景

service-credential 有完整 API（create/update/remove/list，门禁 SERVICE:MANAGE/VIEW）但前端零命中——接入闭环的必经步骤（签发/轮换凭证）只能直连裸调 HTTP；login-log 同样无界面；同步状态零可观测面（sync_metadata/resource_publication_state 无任何 Controller 暴露，对接方问「昨晚全量同步成没成功」只能平台方查库）。注意语义边界：sync_metadata=「最后一次**已应用**同步事件」、resource_publication_state 仅 SUCCESS/PARTIAL——失败尝试（身份/白名单拒绝）先返回不写元数据，只读这两表回答不了「最近一次同步是否失败」。

## 范围

三个管理页面（凭证/登录日志/同步状态）+同步状态端点+菜单种子行。

## 当前口径

三页面全部交付（2026-10-05 拍板 D2=②）。同步页面目标收窄为「已应用状态可见」并明示未知范围；失败证据来源为设计点随卡定稿。页面行=固定图加行，T-ACCESS-086 前置。

## 验收对照

- [ ] 凭证页走 Gateway 可用
- [ ] 登录日志页走 Gateway 可用
- [ ] 同步状态页语义诚实（不虚假呈现无失败）
- [ ] 失败证据设计点定稿记录
- [ ] 固定图加行重建口径注明

## 非目标 / 遗留

- full-sync 异步化/进度查询：不在本计划任何卡（T-PERM-108 同款边界——真实大租户对接出现再立项）。
