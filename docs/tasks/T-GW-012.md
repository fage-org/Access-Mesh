# T-GW-012 sa-token 双端配置对照测试

## 背景

gateway 与 access-service 两份 yml 的 sa-token 配置靠手工对齐（九个共有键的有效值必须一致，否则会话判定两窗漂移）；无双端对照测试、新增键无守卫；valid-seconds 相邻键的「运维同调」注释误导（两窗语义独立）。

## 范围

对照测试+注释修正。不改配置值本身。

## 当前口径

测试规格=共键逐键比较解析后有效值相等+单侧键显式允许清单+新增未登记键即红（不要求两份原始 yml 全等）。

## 验收对照

- [ ] 共键有效值对照测试绿
- [ ] 单侧允许清单+新增键红
- [ ] is-read-header 说明在册
- [ ] 注释修正+红绿实证

## 非目标 / 遗留

- 配置抽公共文件/配置中心统一：不做（两服务配置独立性保留）。
