# T-GW-004 监控指标

> 来源：[gateway-fail-mode-plan](../archive/2026-06-28/gateway-fail-mode-plan.md) 任务 C-4

## 依赖说明

- **T-GW-002**：fail-mode 三模逻辑已实现，指标埋点需要区分三种 fallback 模式。

## 指标设计

### 计数器

| 指标名 | Tag | 含义 | 递增时机 |
|---|---|---|---|
| `gateway.perm.unreachable` | `source=snapshot` | 快照回源不可达 | `loadSnapshot` → `PermCenterUnreachableException` |
| `gateway.perm.unreachable` | `source=check_interface` | fallback check-interface 不可达 | `fallbackCheckInterface` → `PermCenterUnreachableException` |
| `gateway.perm.fallback` | `mode=closed,reason=denied` | fail-closed 拒绝 | `handleUnreachable` CLOSED 分支 |
| `gateway.perm.fallback` | `mode=open,reason=allowed` | fail-open 放行 | `handleUnreachable` OPEN 分支 |
| `gateway.perm.fallback` | `mode=stale,reason=no_entry` | stale-allow 无陈旧条目 | `tryStaleAllow` staleEntry == null |
| `gateway.perm.fallback` | `mode=stale,reason=expired` | stale-allow 条目已过期 | `tryStaleAllow` staleUntil 过期 |
| `gateway.perm.fallback` | `mode=stale,reason=invalidated` | stale-allow 条目被显式失效 | `tryStaleAllow` invalidationMarker 命中 |
| `gateway.perm.fallback` | `mode=stale,reason=allowed` | stale-allow 续命成功 | `tryStaleAllow` ALLOW 放行 |
| `gateway.perm.fallback` | `mode=stale,reason=denied` | stale-allow 快照拒绝 | `tryStaleAllow` DENY/FALLBACK 拒绝 |

> 所有 `gateway.perm.fallback` counter 统一使用 `{mode, reason}` 标签集，保证 Prometheus 同名指标 label set 一致。stale 总数可由 `sum(gateway_perm_fallback_total{mode="stale"})` 聚合。

### Caffeine 缓存指标

`CacheConfig` 通过 `CaffeineCacheMetrics.monitor()` 显式绑定两个 Caffeine Cache 到 MeterRegistry，Actuator 导出：
- `cache_gets{cache=interfaceSnapshotCache,result=hit|miss}`
- `cache_evictions{cache=interfaceSnapshotCache}`
- `cache_load{cache=interfaceSnapshotCache,statistic=duration|count}`

### Prometheus 告警规则

```yaml
# permission-center 不可达告警
- alert: GatewayPermCenterUnreachable
  expr: increase(gateway_perm_unreachable_total[5m]) > 0
  for: 1m
  labels:
    severity: warning
  annotations:
    summary: "Gateway 检测到权限中心不可达"
    description: "Gateway 实例 {{ $labels.instance }} 在过去 5 分钟检测到权限中心不可达 (source={{ $labels.source }})"

# fail-closed 拒绝告警
- alert: GatewayPermFallbackClosed
  expr: increase(gateway_perm_fallback_total{mode="closed",reason="denied"}[5m]) > 10
  for: 2m
  labels:
    severity: critical
  annotations:
    summary: "Gateway 权限校验 fail-closed 拒绝过多"
    description: "Gateway 实例 {{ $labels.instance }} 在过去 5 分钟 fail-closed 拒绝 {{ $value }} 次请求"

# stale-allow 续命但最终拒绝告警
- alert: GatewayPermStaleAllowDenied
  expr: increase(gateway_perm_fallback_total{mode="stale",reason="denied"}[5m]) > 0
  for: 2m
  labels:
    severity: warning
  annotations:
    summary: "Gateway stale-allow 续命但快照拒绝"
    description: "Gateway 实例 {{ $labels.instance }} stale-allow 续命时陈旧快照拒绝请求"
```
