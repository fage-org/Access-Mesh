# T-FE-025 权限授予中栏资源权限概览与授权入口

## 目标

在不调整左栏角色树的前提下，把现有 `PermissionMatrixPanel` 从直接编辑矩阵重构为资源权限概览：展示资源层级、当前有效/直接权限摘要和草稿状态，并通过 Hover/Focus 解释权限来源；提供授权入口打开授权弹窗，点击已有权限标记打开调整弹窗。

## 非目标

- 不实现授权弹窗，归 T-FE-026。
- 不实现右栏变更记录，归 T-FE-028。
- 不恢复原设计中栏批量入口（R5 已确认）。
- 不新增后端有效权限接口；能力不足按设计确认结果降级。

## 实现前确认

- [x] R1：前端阶段只展示可证明的直接、条件、ALL 覆盖和草稿；派生/有效来源待 T-PERM-034 完成时核对，不阻塞本任务。
- [x] R2：状态词、操作简称、颜色与可访问文本。（A1 状态词 + B1 色符字三合一 + WCAG AA，见 §16.8 R2）
- [x] R3：操作摘要"+N"的数量、排序和展开规则。（A1 排序 + B1 显示 3 个 + C1 popover，见 §16.8 R3）
- [x] R5：本轮不恢复原设计中栏批量入口；授权弹窗多选属新交互模型（见 §16.4）。
- [x] R6：ALL、直接实例和操作继承的展示优先级。（A1 优先级 + B1 不自动清理 + C1 文案，见 §16.8 R6）
- [x] R7：GROUP_ROLE 维持只读说明，不伪造有效权限摘要；后端能力核对不阻塞本任务。

## 验收标准

以 frontmatter `acceptance` 为准；全部满足并回写设计后才能进入 done。
