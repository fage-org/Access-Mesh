# T-FE-036 4.1 权限授予页重设计（v3）

> 状态：review（2026-08-02 实现完成 + 自验通过，S1~S7 交互待人工验收）
> 复杂度：🔴 高（重建）
> 后端任务：T-PERM-034（**并行推进，非前置**：本任务以 mock 数据驱动开发，接口形状按设计文档；T-PERM-034 七项改造 + 工程加固见设计文档 §12（第十二轮单入口收敛：list + apply-grant-plan）；组织入口二期（T-ADMIN-021 延后，mock 先行）；联调任务 T-FE-018 拆角色联调首期/组织联调二期）

## 背景

v1/v2 权限授予页于 2026-07-26 因"页面交互不满意"整体删除（归档 `docs/archive/2026-07-26/`），页面处于空窗。
2026-08-01 评审收敛 15 项设计决策（根因：查看与授予两种任务混淆、继承关系未体现），
新设计已回写 `docs/design/frontend/permission-grant.md`（本任务即按该文档实现）。

核心变化 vs v1/v2：

- 查看为主：矩阵（树形资源行 × 可配置操作列）+ 来源图标 + 继承开关（默认开）
- 授权弹窗以**操作权限为维度**（选操作 → 看现状 → 范围+资源 → 条件+canGrant），轻量聚焦
- 子权限/多分支从弹窗移出，放**详情层**（同键多条件 add；子权限增删改走 apply-grant-plan 记录级 creates/updates/removes；草稿虚拟挂载 + 统一提交）
- 变更 = 矩阵就地标记 + 右栏清单 + 统一提交（apply-grant-plan 单入口）
- 三入口共用组件（subjectType 参数）：角色 / 组织（个人入口首期移除，P1-4）

## 实现提示（对齐设计文档）

- **mock 驱动**：开发阶段全部接口走本地 mock 层（形状按 api-contract），与 T-PERM-034 并行；联调（T-FE-018）切真实后端
- 来源链自算：输入 = `list(includeChildren=false)` 主权限（dependOn==null）；`collectDescendants` 资源继承 + `coveredOperations` 操作继承（对齐 `PermQueryEngine` / `OperationPermissionUtils` 语义）；AUTO_DEP 记录只读展示
- 矩阵行：资源树形行 + 每种资源类型顶部「全部资源（ALL）」虚拟行（承载 scopeMode=ALL 记录，与实例行互斥）
- 弹窗确定语义：三键模型（分组键=资源+操作Key+范围，**operationKey = operationCode ?? "bits:"+grantedBits** / 分支键=+条件 / 持久化 id）；匹配仅限 MANUAL 记录（AUTO_DEP 只读不进比对）；范围/资源/操作变化 = 跨键替换（removes 旧 + creates 新，同一 apply-grant-plan 请求内原子，第十二轮收敛，替代旧 rebuild）；仅 canGrant/conditionCode 变更走 updates；**Step 2 现状列表用覆盖位集展开**（`coveredSet = ⋃(bit.binaryBit | bit.inheritMask)` 与目标位比对，含组合位命中；同步第七轮 P1-2 设计文档 §4）
- **单入口提交（第十二轮收敛）**：保存全部只调一次 `apply-grant-plan`（§6.5.1：记录级 plan = creates（主权限可带 children 一次性建树；子权限 `parentPermissionId` 挂父）+ updates（现有记录 canGrant/conditionCode 微变更）+ removes（主权限级联删子/子权限单条删），单事务原子 + 受影响行数断言（无 CAS/幂等表）；跨键替换（范围/资源/操作变化）= removes 旧 + creates 新，原子，子权限不迁移随旧主权限级联删除，变更清单提示；同持久化键已存在 → 20033；旧 save/rebuild/children-save/add-child/update-child/remove-child 均不再使用）
- **提交状态机（第十四轮收窄）**：Pinia `grant-store.ts` 四态 discriminated union（idle/dirty/saving/saveFailed）+ capability（仅门禁与 GROUP_ROLE 派生；AUTO_DEP 为记录级 readonlyReason）；砍八态 + 代际号 + outcomeUnknown list 对比 + 重放；超时 -> 提示刷新确认（详见设计文档 §6.5）
- GROUP_ROLE 只读：展开为基础角色子节点（extra-roles/list），查看/授权目标 = 基础角色
- 门禁：双层（数据源 `ADMIN_ORG:VIEW`/`ADMIN_USER:VIEW`/`ADMIN_ORG:VIEW_POSITION` + 配权 ROLE:VIEW/MANAGE）；个人入口业务键 `PERSONAL_{external_id}` 首期不实现
- 页面级组件（T-FE-036 内自建，不依赖共享池）：条件选择器 = 页面私有轻量组件（搜索 + 摘要 + 启用状态过滤，数据源 `permission-condition/list`，`CONDITION:VIEW` 门控，**不复用 ReConditionEditor**——本页只选已有条件，不编辑规则定义；ReConditionPicker 已随 v1/v2 删除）；角色树/资源树 = 页面级数据适配器（`extra-roles/list` / 资源树接口，T-FE-001 池仅登记不实现）；**组织主体适配器 = 本页自建**（P1-2，依赖 **T-ADMIN-021**：调用扩展 org-tree（includePositions=true，岗位为组织子节点、不分页）；不复用 ReOrgTreePanel——其 loadTree 固定 orgType=1）；详情层改条件 = 重新绑定 conditionCode（选已有条件覆盖）；**错误码提示**：改/删 AUTO_DEP 记录 → 20034 提示"自动补全记录只读"；creates 子权限挂父不存在 → 20009 / 父非主权限 → 20010；同持久化键冲突 → 20033；目标记录不存在 → 20036
- 操作列配置与继承开关为查看态过滤，不影响草稿与数据；**操作列字段名以 `OperationPermissionResp` 为准（code/name，非 operationCode/operationName，P1-4）**
