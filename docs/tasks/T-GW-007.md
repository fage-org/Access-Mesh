# T-GW-007 Gateway CORS 环境化与 actuator 暴露收口

## 背景

gateway/src/main/resources/application.yml:63-66 配置 `allowed-origin-patterns: "*"` 且 `allow-credentials: true`（任意源携带凭证）；:96-99 公开白名单含 /actuator/prometheus 与 /actuator/metrics；:158-168 无 management.server.port（actuator 与主端口 8080 同端口未分离）。纯配置与少量校验代码改动，属试点前安全收口。

## 范围

- CORS origin 环境化、actuator 白名单与端口分离、配置 fail-fast 校验。

## 当前口径

- 最小安全修复：不做 API 网关策略框架、不做配置中心加密方案，仅收口暴露面。

## 非目标 / 遗留

- 不建 Grafana/Prometheus 部署与告警编排（指标保留 Micrometer 现状）。
