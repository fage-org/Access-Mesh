# T-GW-007 Gateway CORS 环境化与 actuator 暴露收口

## 背景

gateway/src/main/resources/application.yml:63-66 配置 `allowed-origin-patterns: "*"` 且 `allow-credentials: true`（任意源携带凭证）；:96-99 公开白名单含 /actuator/prometheus 与 /actuator/metrics；:158-168 无 management.server.port（actuator 与主端口 8080 同端口未分离）。纯配置与少量校验代码改动，属试点前安全收口。

## 范围

- CORS origin 环境化、actuator 白名单与端口分离、配置 fail-fast 校验。

## 当前口径

- 最小安全修复：不做 API 网关策略框架、不做配置中心加密方案，仅收口暴露面。
- 2026-08-25 口径修订：生产 nginx 同源代理（CORS 无生产消费场景），原「生产环境缺失 origin 列表时启动 fail-fast」口径废弃，当前口径为「缺失=默认 localhost / 显式空=禁用，均不放行任意源（fail-closed）」。

## 执行记录（2026-08-25）

- **application.yml**：
  - CORS：`allowed-origin-patterns: ${GATEWAY_CORS_ALLOWED_ORIGINS:http://localhost:8848}`（原 "*"；默认端口取前端 dev 实际端口 8848——VITE_PORT 覆写 vite 原生 5173，直连调试开箱即用），注释块登记四条口径（默认值语义/显式空=禁用/通配 fail-fast/Nacos 覆盖提示）；
  - 白名单：删除 `/actuator/health`、`/actuator/prometheus`、`/actuator/metrics` 三条，注释说明 actuator 迁移管理端口；
  - management 段：新增 `server.port: ${GATEWAY_MANAGEMENT_PORT:8081}` + `server.address: ${GATEWAY_MANAGEMENT_ADDRESS:127.0.0.1}`，注释登记 Nacos 覆盖风险。
- **GatewayProperties**：Whitelist 代码默认值同步删 `/actuator/health`（与 yml 一致）。
- **GatewayCorsConfigValidator（新增，仿 GatewayCacheBoundaryValidator 模式）**：遍历 GlobalCorsProperties 全部配置条目（不依赖单一 key——实测 yml 键 `'[/**]'` 经 Binder 绑定后 map key 为 `/**`，首版用 `[/**]` 取值的实现会静默绕过校验，已修正为条目遍历）；空/未配置 = 允许 + INFO 声明（CORS 禁用，同源终态）；`allowed-origin-patterns` 与兄弟键 `allowed-origins`（exact）两键任意含通配（`*`）且 credentials=true = IllegalStateException 启动失败——exact 键通配若漏到运行期会每请求 500，且 spring-web 的 setAllowedOrigins 不做通配转移（禁用判定须两键皆空）；过滤空白元素兜底空串绑定形态。
- **E2E（BasicRoleGrantVerticalSliceE2EIT）**：gateway 子进程 management 端口改传 E2E 分配的空闲端口（默认 8081 固定值有本机占用/并发冲突风险）；两处就绪探针（首启 + 步骤⑦重启）从主端口 `/actuator/health` 迁移到 `http://127.0.0.1:<管理端口>/actuator/health`——探针迁移本身由失败暴露：管理端口分离后主端口探测 404，正是「探针改访问管理端口」的第一个真实消费者。
- **测试**：`GatewayCorsConfigValidatorTest` 9 用例（明确列表通过/未配置允许/空列表=禁用/空白元素过滤/通配+credentials 拒绝×2（含子域通配）/通配无 credentials 允许/allowed-origins(exact) 通配拦截×2）；`GatewayApplicationConfigTest` 补 CORS 绑定断言（默认 localhost:8848 + credentials true）、白名单无 /actuator 断言、management 端口绑定断言（8081/127.0.0.1）。

## 验证证据（2026-08-25）

- `mvn test -pl gateway -DskipTestcontainers=true`：**93 用例，0 失败**（基线 83 + ValidatorTest 9 + ConfigTest 新增 1 方法）。
- `mvn test -pl gateway`（含容器轨）：**E2E 8/8 全绿**（双子进程真实启动；日志实证 GatewayCorsConfigValidator 在真实子进程通过、就绪探针经管理端口工作、步骤⑦重启链路正常；E2E freePort 绑定 127.0.0.1 与服务端口地址族一致）。
- 主端口无 actuator 的行为证明：管理端口分离后主端口 `/actuator/health` 探测 404（E2E 迁移前失败的直接证据）。
