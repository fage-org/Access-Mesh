# T-FE-058 岗位与成员角色候选分页闭合

## 背景

承接[评审证据](../archive/2026-09-20/comprehensive-review.md)的 F008；基线与静态/动态证据强度见该记录。实施与验证见完成记录。

## 范围

- PositionTab岗位列表与成员候选远程搜索分页；UserDetailPanel功能角色候选及管理轨role/list消费者。
- 保留已选择项和正确loading/错误反馈，复用现有分页/选择器实现。

## 当前口径

方案唯一入口：[IAM闭环方案](../design/iam-task-closure.md#pagination)。实施定案（2026-09-23 用户拍板，三项）：

- **U005=迁移+同批退役**：UserDetailPanel 功能角色候选迁 `/api/access/abstract-role/list`（`roleTypeCodes=[BASIC_ROLE,GROUP_ROLE,PERSONAL]` + keyword + 分页）；`/api/access/role/list` 同批退役——删 AdminRoleController 端点链、契约 §10.2 改退役注记、bootstrap 固定图 API 行移除、存量库订正语句登记 runbook。有限管理员候选可见面随迁移对齐角色管理页实例准入口径（分配动作仍受 USER_ROLE_ASSIGN 门禁）。
- **选择器形态=el-select 远程搜索+下拉内翻页**：remote-method 远程搜词 + #footer 插槽上一页/下一页；已选项跨翻页/换词保留（已选缓存合并渲染标签），提交对象取自缓存不取自当前页。成员候选与角色候选两处同形态，不引入新通用组件框架（局部 composable）。
- **Q-035/Q-036 随卡收敛**：新增岗位弹窗改传 parentOrgId/parentOrgName prop（对齐 index.vue openOrgForm 先例）；index.vue 传入 org-tree prop 修复「位置」列父路径解析；展开成员失败态与空态区分（失败=错误占位可重试，非「暂无成员」）。

岗位管理列表用 `/org/page` 既有 `orgName` 模糊+分页（服务端搜索替代本地过滤，卡片列表+底部分页）；成员候选用 `/user/member-candidates` 既有 keyword+分页（用户目录不照搬字典拉全）。两后端端点零改动。
