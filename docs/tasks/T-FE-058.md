# T-FE-058 岗位与成员角色候选分页闭合

## 背景

承接[评审证据](../archive/2026-09-20/comprehensive-review.md)的 F008；基线与静态/动态证据强度见该记录。任务尚未实施，已有测试通过不代表该问题已解决。

## 范围

- PositionTab岗位列表与成员候选远程搜索分页；UserDetailPanel功能角色候选及管理轨role/list消费者。
- 保留已选择项和正确loading/错误反馈，复用现有分页/选择器实现。

## 当前口径

方案唯一入口：[IAM闭环方案](../design/iam-task-closure.md#pagination)。该方案为draft；沿用其推荐方向编排，涉及现行定案变化时先解决本卡待决项并回写权威来源，再实施。

**待决与启动核实**：U005：管理轨role/list升级分页还是迁移到既有分页端点？先核消费者和权限差异，选择改动最小且不放宽数据范围者。

## 验收对照

唯一验收清单见 frontmatter `acceptance`；设计回写、状态同步和验证按项目生命周期收口要求执行。

## 非目标 / 遗留

本卡只覆盖上述闭环，不自动扩展相邻产品能力；已有暂缓事项仍沿原任务。新发现且不能在本卡收敛的独立事项按项目生命周期登记，禁止把未知结果写为完成。
