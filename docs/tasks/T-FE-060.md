# T-FE-060 授权决策与展示键无歧义编码

## 背景

承接 [Q-044](../pending-problems.md#q-044) 前端半边：code/codeType 可含分隔符，而前端授权决策与展示多处直接拼串做键——碰撞可错预填、使 `uncheckSlot` 的 suspended 去重吞撤销、混并矩阵来源行、影响高亮。与后端半边（T-PERM-096）修法面独立，可并行。

## 范围

grant-plan.ts 三键函数、computePreset/GrantDialog.vue 节点映射、source-chain.ts、subject-tree.ts、GrantChildConfigurator 反查；编码方式单源（一个键构造模块），不逐处各拼各的。

## 当前口径

现状四处拼法不一致（| 与 : 并存）。任务内定前端统一编码形态（结构化键对象或无歧义序列化），后端协议键不受本任务影响。

## 非目标 / 遗留

- 后端内存索引元组化（T-PERM-096）。
- 前端对外请求载荷形态（后端 DTO 字段不变）。
