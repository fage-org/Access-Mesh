# T-FE-060 授权决策与展示键无歧义编码

## 完成记录（2026-10-01 收口）

- **单源编码模块**：新建 `utils/grant-keys.ts`——`encodeKeyTuple`（JSON 数组元组编码：各段经 JSON 转义、任何分隔符组合不可能歧义；`undefined` 统一编码为 `null`，与 findSlotRecord 等 `?? null` 字段直比语义对齐）+ 五个键构造器（`grantTupleKey`/`resourceTupleKey`/`resourceNodeKey`/`roleSubjectKey` 及行键族经 `encodeKeyTuple("ALL"/"RES",…)`）。
- **消费面接线**：grant-plan.ts 三键函数（groupKeyOf/slotKeyOf/resourceGroupKeyOf）改委托构造器；computePreset.checkedTripleKeys 与 GrantDialog.nodeKeyOf/idByTripleKey 统一走 `resourceNodeKey`（同构闭环）；source-chain.ts 的 instanceRowKey/allRowKey 改元组编码；subject-tree.ts 角色键改 `roleSubjectKey`（externalId 与数字 id 分命名空间 `role:ext:`/`role:id:`）；GrantChildConfigurator 子权限反查（manualChildrenByKey 构造与查询同源走 groupKeyOf）自动跟随。
- **类推命中顺带修**：types.ts `changeGroupKey`（变更清单分组键）inlineName 为用户自由文本可含 `|`，旧拼接可使两变更误并一组展示——同批改 `encodeKeyTuple` 五段。
- **golden fixture 适配**：source-chain.spec 期望侧 rekeyRow——fixture 历史 `RES:`/`ALL:` 行键字面值按 case resources 无歧义重建映射到新编码（构造方向无歧义），fixture 数据本身不动。
- **回归锁（旧实现实证红，stash 三实现文件跑 spec 共 8 红）**：groupKeyOf/resourceGroupKeyOf 碰撞对互异；computePreset 碰撞对不混预填（size=2）；uncheckSlot 碰撞槽位先后取消互不吞撤销（suspended size=2 + expandSuspended 生成两条 remove）；instanceRowKey 碰撞对互异；subject-tree 数字 externalId="5" 与 id=5 键不混并。3 个既有 computePreset 用例断言同步改构造器生成（旧字面值断言随编码切换失效，属预期连带）。
- **验证**：vitest 459/459 全绿；typecheck/lint:eslint/build 全 0。
- **文档**：permission-grant.md 新增 §2.3 键约定（五键构造器/消费面表 + 「不进请求载荷、后端 DTO 不变」边界）；types.ts SubjectTreeNode.key 注释同步。

## 背景

承接 [Q-044](../pending-problems.md#q-044) 前端半边：code/codeType 可含分隔符，而前端授权决策与展示多处直接拼串做键——碰撞可错预填、使 `uncheckSlot` 的 suspended 去重吞撤销、混并矩阵来源行、影响高亮。与后端半边（T-PERM-096）修法面独立，可并行。

## 范围

grant-plan.ts 三键函数、computePreset/GrantDialog.vue 节点映射、source-chain.ts、subject-tree.ts、GrantChildConfigurator 反查；编码方式单源（一个键构造模块），不逐处各拼各的。

## 当前口径

现状四处拼法不一致（| 与 : 并存）。任务内定前端统一编码形态（结构化键对象或无歧义序列化），后端协议键不受本任务影响。——已定：JSON 元组编码单源（见完成记录）。

## 非目标 / 遗留

- 后端内存索引元组化（T-PERM-096，同日完成）。
- 前端对外请求载荷形态（后端 DTO 字段不变）。
