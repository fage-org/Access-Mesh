# T-FE-024 ReConditionPicker + ReConditionEditor

> 状态：proposed
> 复杂度：🟡 中
> 来源：T-FE-001 组件池汇总确认派生（2026-07-12）

## 背景

T-FE-001 跨页组件抽象池汇总确认：权限条件选择器 + 规则编辑器在 T-FE-009（条件管理页独立 CRUD）和 T-FE-014（权限授予页附加设置弹窗内联新建）两处使用，模式一致（搜索/摘要/启用状态/内联新建/规则序列化校验），确认抽取为共享组件。

T-FE-014 §15.4 明确：「条件编辑/选择器已达第二个使用场景，确认后续抽取 ReConditionPicker/ReConditionEditor」。

## 组件设计

### ReConditionPicker

- 按名称/编码搜索条件
- 展示规则摘要 + Gateway 可评估状态（gatewayEvaluable，T-PERM-017）
- 只列启用条件；已绑定后停用的条件可回显但保存前需替换或清除
- CONDITION:CREATE 权限时显示「新建条件」入口，创建成功后自动选中并回到当前弹窗
- 无创建权限时不展示不可用入口

### ReConditionEditor

- 从 ConditionForm 抽取结构化编辑器
- logic AND/OR + items[] 4 类型（DATE_RANGE/TIME_RANGE/IP_WHITELIST/IP_BLACKLIST）
- params 动态表单（date/time-picker + cidrs tag 输入）
- 规则序列化 + 校验逻辑共享（两处必须使用同一规则模型）
- gatewayEvaluable 开关 + 白名单预校验（T-PERM-017）

## 改造范围

- 新建 `frontend/src/components/ReConditionPicker/`（barrel 导出）
- 新建 `frontend/src/components/ReConditionEditor/`（barrel 导出）
- T-FE-009 `views/system/permission-condition/components/ConditionForm.vue` -> 使用 ReConditionEditor
- T-FE-014 `views/system/permission-grant/components/AdditionalSettingDialog.vue` -> 使用 ReConditionPicker + ReConditionEditor（内联新建路径）
