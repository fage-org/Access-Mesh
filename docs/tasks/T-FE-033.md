# T-FE-033 子权限矩阵展开（parentVariantId）+ 两步保存 + 条件清除 wire

## 目标

实现子权限按父变体挂载、两步保存（PermCellKey+conditionCode 匹配响应）、条件清除 wire 约定。

## 非目标

- 不实现保存前总览与失败恢复（T-FE-034）。

## 实现要点

- ChildPermissionInline（V2 独立，按 parentVariantId binding）。
- saveAll 两步：主 save -> 匹配响应 -> add-child/remove-child。
- 条件清除适配层：`toUpdateItem` 把清除序列化为 conditionCode=""。

以 frontmatter `acceptance` 为准。
