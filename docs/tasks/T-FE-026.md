# T-FE-026 权限授予授权弹窗（批量授权任务）

## 目标

实现授权弹窗作为批量授权任务的唯一入口：一个角色 + 一个资源类型 + 多个操作（多选）+ 多个资源（多选）+ 一组条件配置，确认为一条变更记录。支持新建授权和调整已有权限（含移除）。

## 非目标

- 不实现中栏资源概览与授权入口，归 T-FE-025。
- 不实现右栏变更记录展示，归 T-FE-028。
- 不抽取 ReConditionPicker/ReConditionEditor/ChildPermissionInline，归 T-FE-024。
- 不改变后端保存顺序和子权限部分失败语义。

## 实现前确认

- [x] R4：弹窗尺寸与内联组件承载。（大尺寸居中 Dialog + 步骤导航 + 内联子权限/附加设置，见 §16.8 R4）
- [x] R9：T-FE-024 先于 T-FE-026，ChildPermissionDrawer 内联化归 T-FE-024。

## 决策记录（2026-07-12）

### 1. 任务快照数据模型（方案 A+）

引入 `GrantTaskSnapshot[]`（`grantTasks`）作为授权意图与分组快照，支持 T-FE-028 恢复编辑。约束：

- store 提供 `commitGrantTask` / `replaceGrantTask` / `removeGrantTask` / `clearGrantTask` 原子操作。
- `mainDraft` / `childDraft` 为 computed，由 `baseline + 有序 grantTasks` 重放生成（`replayGrantTasks` 纯函数，独立文件 `utils/grant-task.ts`），仍是 `saveAll` 唯一输入。
- `discardAll` 同步清空 `grantTasks + failedChildren + saveError`；`selectRole` / `reloadBaseline` 成功分支同步清空 `grantTasks`。
- 旧 `revertDiff`（单项撤销）移除；右栏过渡提示"当前暂不支持单条撤销，可放弃全部；任务粒度撤销将在 T-FE-028 提供"。
- `replaceGrantTask` 保持原数组位置、`taskId`、`createdAt`，避免编辑导致任务重排。
- `commit` / `replace` 时校验任务角色与域与当前上下文一致，防止过期弹窗提交。

### 2. R11 显式"保留直接记录"开关

不采用纯静默跳过。`GrantTaskSnapshot.keepDirectWhenAllCovered`（默认 false）：

- 资源正常勾选，不默认取消。
- 存在"被 ALL 覆盖且 baseline 无直接记录"的组合时，步骤三显示批量开关 `仍创建直接记录`（默认关闭）。
- 关闭时 replay 跳过这些组合（`redundantSkipped`），确认摘要显示数量。
- 开启时创建直接记录；该字段进入快照，编辑时恢复。
- 已存在直接记录的组合不跳过，按相同配置无变化、不同配置修改处理。

R11 判断口径：replay 从 baseline 起步后只检查当前投影 `main.has(instanceKey)` / `main.has(allKey)`，不额外 OR baseline（前序任务移除 ALL 后后续不误判覆盖）。

### 3. 子权限完整集合替换（支持删除）

`TaskChildGroup` 存在时 `children` 为该父权限最终期望的完整集合：

- group 存在：replay 先删除当前投影中该 `parentKey` 前缀下的子项，再写入完整集合。
- group 缺失：本任务不修改该父权限的子权限。
- group 存在且 `children=[]`：明确移除该父权限的全部子权限。
- `TaskChildGroup` 含 `parentKey`（子键前缀）+ 操作/资源字段（展示用）。

弹窗步骤四 `el-collapse` 展开某主权限组合时，初始化本地草稿为该 `parentKey` 的 baseline 子权限副本（完整集合替换基准）；用户新增/移除后，`children` 反映最终期望。确认时仅提交展开过的组合。

### 4. 键一致 + 原子合并

- 主键使用 `permCellKey`；子键使用 `childPermCellKey(parentKey, child)`（共享纯函数，从 hook 抽到 `@/utils/permission-grant-types`）。
- 新主权限的子权限 `dependOn=null`、`dependOnTempKey=parentKey`；已保存主权限使用真实 `dependOn`。
- 弹窗本地键与页面键完全一致，但确认时通过 `store.commitGrantTask` 原子合并，弹窗组件不直接修改 `store.childDraft.value`。

### 5. 条件拆分静态提示

步骤三仅在 `selectedOps.size > 1` 时显示提示："本组条件和 canGrant 将应用于全部所选操作与资源；如需按操作配置不同条件，请拆分为多次授权。"确认摘要展示"同一配置将应用于 N 个操作 × M 个资源"，不做动态意图检测。

### 6. 保存失败链改造

`mainDraft` / `childDraft` 改 computed 后，`saveAll` / `retryFailedChildren` 同步改造：

- 投影顺序：`baseline -> grantTasks -> failedChildren overlay`（overlay 在 `childDraft` computed 中叠加，replay 纯函数不感知）。
- `saveAll` 先捕获 `mainDiff` / `childDiff`（含 overlay），再清 `failedChildren`，避免重试 diff 提前消失。
- 部分失败重载 baseline 后：`grantTasks` 已由 `reloadBaseline` 成功分支清空，失败子权限写回 `failedChildren` overlay。
- stale 重试：备份失败操作 -> `reloadBaseline` -> 恢复 overlay -> `saveAll`。
- 删除 `applyChildOpsToDraft`（不再直接赋值 computed draft）。

### 7. 能力门禁

不循环发权限查询。步骤一操作不可授予用 `store.isGrantableByOperator`（现有 capability 保守判定，fail-closed）；步骤二资源"已有/部分已有"从 baseline 判定（不发查询）。最终以后端批量授权校验为准。

## 实现说明

### 文件改动

- `utils/permission-grant-types.ts`：新增 `childPermCellKey` 共享纯函数 + `GrantTaskSnapshot` / `TaskResource` / `TaskChildGroup` / `GrantTaskIntent` 类型。
- `utils/grant-task.ts`（新建）：`replayGrantTasks` 纯函数 + `GrantTaskEffect` / `GrantTaskReplayResult` 类型（`taskEffects` 记录 add/update/remove/noChange/redundantSkipped + 贡献键，供 T-FE-028 分组展示）。
- `utils/hook.ts`：`grantTasks` ref + `mainDraft`/`childDraft` 改 computed（replay + failedChildren overlay）；新增 `commitGrantTask`/`replaceGrantTask`/`removeGrantTask`/`clearGrantTask`；移除 `toggleMainCell`/`setMainCellAttr`/`toggleChildCell`/`setChildCellAttr`/`childKeyOf`/`revertDiff`/`applyChildOpsToDraft`/`resolveResourceName`（无调用方）；`saveAll`/`retryFailedChildren`/`discardAll`/`selectRole`/`reloadBaseline` 同步改造。
- `components/GrantDialog.vue`（新建）：四步授权弹窗（操作多选 -> 资源多选 -> 条件/canGrant/R11 开关 -> 子权限逐项可跳过）+ 调整模式预填 + 移除动作。
- `components/RightPanel.vue`：移除单项撤销按钮 + `onRevert`；加过渡提示。
- `index.vue`：接入 `GrantDialog`（`grantTrigger` ref + `onOpenGrant`/`onOpenAdjust`/`onCloseGrant`）。
