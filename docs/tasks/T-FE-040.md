# T-FE-040 4.1 权限授予弹窗 v3.1 记录级聚焦编辑

> 状态：proposed（2026-08-08 决策记录 `permission-grant-record-level-editing-proposal.md` 已确认 D1~D6 及补充决策；本任务承接 v3.1 前端改造，T-FE-036 定位 v3 历史任务）
> 依赖：**mock-first（已确认）**——mock 阶段不依赖后端任务；真实接口联调（T-FE-018）前需完成 T-PERM-034（apply-grant-plan 扩展：20042/20043、sub-perm-allowed-types、SubPermissionPolicy）与 T-PERM-041（主权限条件不变量）
> 前置验收：见 acceptance（DoD 门禁）

## 背景

T-FE-036 实现的是 v3 共享设置模式（弹窗条件/再授予统一应用于已勾选授权）。v3.1 决策（2026-08-08 确认）改为**记录级聚焦编辑**：复选框只控制授权新增/保留/撤销，点击资源行聚焦后设置区只读取和修改该聚焦记录；新勾选资源使用固定默认值；无任何隐式或批量覆盖。交互细节（焦点生命周期、显式复制、停用条件、子权限入口、节点摘要）以 permission-grant.md v3.1 与决策记录 §11 为唯一权威。

## 范围

1. 授权弹窗记录级聚焦编辑（§S1/S2）：焦点生命周期、initial 完整键、复选框/整行分离、ALL 焦点迁移、suspended 双路径
2. 显式复制（§S3）：复制弹窗、合并规则、归一化删除、源条件停用禁用
3. 停用条件与条件门禁移除（§S4/S5）：选择器限启用、存量标注、CONDITION:VIEW 全量移除（条件管理页+授权页）
4. 子权限记录级入口（§S6）：SUB_PERM 允许集过滤、候选三态、20043 提示
5. 节点紧凑摘要（§S7）

不在范围：后端 20042/20043 校验（T-PERM-034/T-PERM-041）、sub-perm-allowed-types 后端实现（T-PERM-034）。
