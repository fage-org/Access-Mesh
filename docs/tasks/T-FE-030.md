# T-FE-030 方案A前端模型（GrantVariantId + replay + 聚合摘要）

## 目标

实现方案 A 多条件分支模型的纯数据层：身份、存储、replay、聚合摘要、不变量。

## 非目标

- 不实现 UI 渲染（T-FE-031）。
- 不实现保存/网络（T-FE-033/034）。

## 实现要点

- `utils/grant-variant.ts`：GrantVariantId 类型 + Map 存储 + PermCellKey 索引维护。
- `utils/replay.ts`：replayGrantTasks 纯函数（含 taskEffects 供右栏分组）。
- `utils/aggregate.ts`：单元格聚合摘要（SummaryEffective + SummaryDraftChange）。
- **搭建 Vitest**：`package.json` 加 `test` 脚本 + vitest 依赖 + 配置（首个前端测试任务，建立基础设施供后续任务复用）。
- 单元测试覆盖不变量（§7.1）与聚合规则。

## 验收标准

以 frontmatter `acceptance` 为准；纯函数单元测试通过。
