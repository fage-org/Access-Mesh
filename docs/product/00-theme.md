# 配色主题与响应式设计

## 配色方案

| 元素 | 建议 |
|------|------|
| 主色调 | 蓝色系 (#409EFF) — Element Plus 默认蓝 |
| 状态-启用 | 绿色 Tag (#67C23A) |
| 状态-停用 | 红色 Tag (#F56C6C) |
| 状态-警告 | 橙色 Tag (#E6A23C) |
| 权限-允许 | 绿色图标 + 文字 |
| 权限-拒绝 | 红色图标 + 文字 |
| 变更-新增 | 绿色 (#67C23A) |
| 变更-删除 | 红色 (#F56C6C) |
| 变更-修改 | 蓝色 (#409EFF) |
| 影响-直接 | 红色 Badge |
| 影响-可能 | 橙色 Badge |

| 场景 | 图标 |

| 角色类型-BASIC | 🔑 钥匙图标 |
| 角色类型-ORG | 🏢 建筑图标 |
| 角色类型-GROUP | 📦 包裹图标 |
| 角色类型-POSITION | 💼 公文包图标 |

## 响应式设计

| 断点 | 宽度 | 布局调整 |
|------|------|----------|
| 桌面 | ≥ 1280px | 左侧菜单展开 + 树+详情双栏布局 |
| 平板 | 768-1279px | 左侧菜单折叠 + 树+详情切换为 Tab |
| 移动 | < 768px | 不优先支持，管理端以桌面为主 |
