# 操作权限

## 页面路径

`/permission/operation`

## 页面描述

管理操作权限（OperationPermission），定义资源上可执行的操作码。

## 表格列定义

| 列名 | 字段 | 说明 |
|------|------|------|
| 操作码 | operationCode | 如 VIEW, MANAGE, ACCESS, DATA_READ, DATA_EDIT |
| 名称 | operationName | 操作中文名称 |
| 资源类型 | resourceTypes | 适用资源类型列表，Tag 展示 |
| 权限位 | permissionBit | 位运算值，如 bit 1, bit 2 |
| 状态 | status | 启用/停用 |
| 操作 | — | 编辑、删除 |

## 新建/编辑操作表单

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 操作码 | 文本 | 是 | 大写字母+下划线，如 VIEW |
| 操作名称 | 文本 | 是 | 中文名称 |
| 适用资源类型 | 多选 | 是 | MENU/API/DATA_SCOPE（BUTTON 不需要操作码，授予即拥有） |
| 权限位 | 数字 | 是 | 2 的幂次，如 1, 2, 4, 8, 16 |
| 描述 | 文本域 | 否 | 操作说明 |
| 状态 | 开关 | 是 | 默认启用 |

## 预设操作码

| 操作码 | 名称 | 适用资源 | 权限位 |
|--------|------|---------|--------|
| VIEW | 查看 | MENU | 1 |
| MANAGE | 管理 | MENU | 2 |
| ACCESS | 访问 | API | 4 |
| DATA_READ | 数据读取 | DATA_SCOPE | 8 |
| DATA_EDIT | 数据编辑 | DATA_SCOPE | 16 |

## 交互说明

- 操作码是权限授权页面中「操作面板」的数据来源
- 权限位用于位运算，支持多操作权限合并计算
- 删除操作权限前需检查是否有角色引用，有则阻止
