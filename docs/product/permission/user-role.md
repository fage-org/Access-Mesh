# 用户角色

## 页面路径

`/permission/user-role`

## 页面描述

管理用户与角色的关联关系，支持按用户查看/分配角色，也支持按角色查看/分配用户。

## API 调用

| 操作 | API | 说明 |
|------|-----|------|
| 查询用户角色 | `user-role/list` | 按用户查询时传入 userId |
| 分配角色 | `user-role/assign` | 单个用户分配单个角色 |
| 批量分配 | `user-role/batch-assign` | 单个用户分配多个角色 |
| 回收角色 | `user-role/revoke` | 回收用户的某个角色 |

## 交互说明

- 按用户视图：列表展示用户，「分配」按钮打开角色选择器，支持多选
- 按角色视图：列表展示角色，「查看」按钮打开该角色的用户列表弹窗
- 回收角色需二次确认
- 批量分配调用 `user-role/batch-assign`，一次提交多个角色
- 支持 URL 参数 `?userId=xxx` 或 `?roleId=xxx` 直接定位
