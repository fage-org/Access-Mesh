# 权限授权

## 页面路径

`/permission/grant`

## 页面描述

为角色配置资源权限。左侧选择角色，中间按资源类型操作授权，右侧实时预览本次修改的变更清单。MENU/API/DATA_SCOPE 资源通过勾选操作码授权，BUTTON 资源勾选即授权（无需操作码）。支持子权限（scope）管理。

## 左侧：角色树

| 功能 | 说明 |
|------|------|
| 分组展示 | 按角色类型分组（基础/组织/分组/职位/个人） |
| 搜索过滤 | 输入关键词过滤角色节点 |
| 节点图标 | 按角色类型显示不同图标（🔑/🏢/📦/💼/👤） |
| 选中状态 | 点击角色节点高亮，中间区域加载该角色的已有权限 |
| 权限数标记 | 节点旁显示已授权数量 Badge |

## 中间：操作区

### 上层：工具栏（一行）

| 元素 | 说明 |
|------|------|
| 资源类型 | 切换按钮组：🍃菜单 / 🔘按钮 / 🔌API / 📊数据范围，控制下方资源树的数据范围 |
| 全选 | 勾选/取消当前类型下所有资源的默认操作权限 |
| 操作码 | 根据资源类型动态展示：菜单→VIEW/MANAGE，API→ACCESS，数据范围→DATA_READ/DATA_EDIT；按钮类型不显示 |
| 搜索 | 过滤下方资源树节点 |

- 切换资源类型时，下方资源树刷新为对应类型的资源
- 勾选操作码复选框后，在资源树中点击某个资源节点即授予该操作码（快捷批量操作）

### 下层：资源树

- 按当前选中的资源类型展示对应资源
- 每个节点行内显示已拥有的操作权限状态（如 ✅VIEW ✅MANAGE）
- BUTTON 类型节点仅显示 ✅ 或 ❌（无操作码）
- 节点前的 checkbox 用于勾选/取消授权
- 树形层级关系保持（菜单下有子菜单、按钮挂在菜单下等）

## 右侧：变更清单

实时展示本次编辑的权限变化，保存前可确认和清空。

### 变更分类

| 类别 | 颜色 | 说明 |
|------|------|------|
| 🟢 新增 | 绿色 | 本次新授予的权限 |
| 🔴 移除 | 红色 | 本次回收的权限 |
| 🔵 修改 | 蓝色 | 操作码变更（如新增 MANAGE） |

### 变更条目格式

```
+ 用户管理 → VIEW          （新增：授予用户管理菜单的 VIEW 操作）
+ 新增按钮                  （新增：授予按钮权限）
- 删除按钮                  （移除：回收按钮权限）
~ 组织管理 +MANAGE          （修改：组织管理菜单新增 MANAGE 操作码）
~ 资源管理 -DATA_EDIT       （修改：资源管理数据范围移除 DATA_EDIT 操作码）
```

### 交互

- 每次勾选/取消勾选资源或操作码，变更清单实时更新
- 点击变更条目可展开详情（所属角色、资源类型等）
- 「清空变更」按钮重置所有修改，恢复到上次保存的状态
- 变更清单为空时显示「暂无修改」

## 条件权限配置

### 条件权限说明

| 元素 | 说明 |
|------|------|
| 条件模式 | 「无条件」= 权限始终生效；「绑定条件」= 仅满足条件时权限生效 |
| 选择条件 | 从系统配置的权限条件列表中选择，支持多选 |
| 多条件关系 | AND = 所有条件都满足才生效；OR = 任一条件满足即生效 |
| 已选条件预览 | 展示已选条件的名称和规则摘要 |
| 变更追踪 | 条件的绑定/解绑也纳入右侧变更清单，随权限一起保存 |

## 保存逻辑

使用三段式保存 API `role-resource-permission/save`：

```json
{
  "roleId": 1,
  "add": [
    { "resourceId": 10, "operationIds": [1, 2] }
  ],
  "update": [
    { "resourceId": 20, "operationIds": [1] }
  ],
  "remove": [
    { "resourceId": 30, "operationIds": [2] }
  ]
}
```

- `add`：新增的授权项（变更清单中的 🟢 新增）
- `update`：修改的授权项（变更清单中的 🔵 修改）
- `remove`：回收的授权项（变更清单中的 🔴 移除）
- 三段在同一个事务中执行

## 交互说明

- 页面进入时，左侧加载角色树，点击角色后中间区域通过 `role-resource-permission/list` 加载已有权限
- 切换角色时，如有未保存变更则提示确认
- 中间区域的所有勾选/取消操作实时反映到右侧变更清单
- 工具栏的操作码复选框用于「快捷模式」：勾选 VIEW 后点击资源节点自动授予 VIEW
- 「全选」勾选当前资源类型下所有资源的默认操作码
- 点击「保存」将变更清单中的差异以 add/update/remove 三段提交
- 点击「重置」恢复到上次保存的状态，清空变更清单
- 保存成功后显示成功提示并清空变更清单
