# 资源管理

## 页面路径

`/permission/resource`

## 页面描述

管理权限中心的资源实体（ResourceEntity），支持菜单、按钮、API、数据范围四种资源类型的树形管理。

## 左侧：资源树

| 功能 | 说明 |
|------|------|
| 类型过滤 | 可按资源类型筛选（菜单/按钮/API/数据范围） |
| 搜索过滤 | 输入关键词过滤节点 |
| 节点图标 | 菜单📄、按钮🔘、API🔌、数据📊 |
| 右键菜单 | 新建子资源、编辑、移动、复制、删除、启停用 |
| 拖拽排序 | 支持拖拽调整层级和顺序 |

## 右侧：资源详情

### 基本信息区

| 字段 | 说明 |
|------|------|
| 名称 | 资源显示名称 |
| 类型 | MENU / BUTTON / API / DATA_SCOPE |
| 编码 | 资源唯一编码 (resourceCode) |
| 路径 | 前端路由路径（菜单类型） |
| 组件 | Vue 组件路径（菜单类型） |
| 排序 | 同级排序值 |
| 状态 | 启用/停用 |

### 子资源列表

- 展示当前资源的直接子资源
- 支持新建子资源和批量创建
- 支持编辑、删除、启停

## 新建/编辑资源表单

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 资源名称 | 文本 | 是 | 1-100 字符 |
| 资源类型 | 下拉 | 是 | MENU/BUTTON/API/DATA_SCOPE |
| 资源编码 | 文本 | 是 | 格式：`模块:资源` 如 `sys:user` |
| 上级资源 | 树形选择 | 否 | 选择父资源 |
| 路由路径 | 文本 | 菜单必填 | 如 `/user/list` |
| 组件路径 | 文本 | 菜单选填 | 如 `views/user/list/index.vue` |
| 图标 | 图标选择器 | 否 | Iconify 图标 |
| 排序 | 数字 | 是 | 默认 0 |
| 是否隐藏 | 开关 | 否 | 不在菜单中显示 |
| 状态 | 开关 | 是 | 默认启用 |

## 批量创建

支持一次创建多个同级资源（如为某个菜单批量创建按钮权限）：

```
┌─ 批量创建子资源 ──────────────────────┐
│ 上级资源: 用户管理 (sys:user)          │
│                                        │
│ ┌──────┬──────┬──────┬──────┐          │
│ │名称  │ 类型 │ 编码 │操作  │          │
│ ├──────┼──────┼──────┼──────┤          │
│ │查看  │BUTTON│view  │ 🗑️   │          │
│ │新增  │BUTTON│add   │ 🗑️   │          │
│ │编辑  │BUTTON│edit  │ 🗑️   │          │
│ │删除  │BUTTON│delete│ 🗑️   │          │
│ └──────┴──────┴──────┴──────┘          │
│ [+ 添加行]                             │
│                                        │
│           [取消]  [确认创建]           │
└────────────────────────────────────────┘
```

## 交互说明

- 点击左侧资源节点，右侧刷新显示资源详情
- 批量创建调用 `resource-entity/batch-create` 接口
- 移动资源调用 `resource-entity/move` 接口
- 删除资源会级联删除所有子资源（需确认）
