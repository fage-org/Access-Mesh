# 角色管理

## 页面路径

`/permission/role`

## 页面描述

管理权限中心的抽象角色（AbstractRole），支持树形结构展示和五种角色类型。

## 左侧：角色树

| 功能 | 说明 |
|------|------|
| 分组展示 | 按角色类型分组（基础/组织/分组/职位/个人） |
| 搜索过滤 | 输入关键词过滤节点 |
| 树形层级 | 支持父子层级（如基础角色下有子角色） |
| 右键菜单 | 新建子角色、编辑、移动、复制、删除、启停用 |
| 节点图标 | 按角色类型显示不同图标（🔑/🏢/📦/💼/👤） |

## 右侧：角色详情

### 基本信息区

| 字段 | 说明 |
|------|------|
| 名称 | 角色显示名称 |
| 类型 | BASIC / ORG / GROUP / POSITION / PERSONAL |
| 编码 | 角色唯一编码 (roleCode) |
| 状态 | 启用/停用 |
| 描述 | 角色说明 |
| 创建时间 | 创建时间 |

### 子角色列表

- 如果该角色有子角色，展示子角色表格
- 支持新建子角色（自动以当前角色为父）
- 支持编辑、删除、启停子角色

### 操作按钮区

| 按钮 | 行为 |
|------|------|
| 配置权限 | 跳转 `/permission/grant?roleId=xxx` |
| 分配用户 | 跳转 `/permission/user-role?roleId=xxx` |
| 编辑 | 打开编辑弹窗 |
| 复制角色 | 以当前角色为模板创建新角色 |
| 删除 | 二次确认，有关联用户时提示先回收 |

## 新建/编辑角色表单

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 角色名称 | 文本 | 是 | 1-100 字符 |
| 角色类型 | 下拉 | 是 | BASIC/ORG/GROUP/POSITION/PERSONAL |
| 角色编码 | 文本 | 是 | 唯一标识，创建后不可修改 |
| 上级角色 | 树形选择 | 否 | 选择父角色 |
| 外部ID | 文本 | 否 | 关联外部系统的角色ID |
| 描述 | 文本域 | 否 | 角色说明 |
| 状态 | 开关 | 是 | 默认启用 |

## 分组角色管理（Extra Roles）

角色详情中有一个「分组角色」Tab，用于管理 GROUP 类型角色的子角色：

| 操作 | API | 说明 |
|------|-----|------|
| 查看分组角色 | `abstract-role/extra-roles/list` | 列表展示 |
| 添加分组角色 | `abstract-role/extra-roles/add` | 从角色列表选择添加 |
| 移除分组角色 | `abstract-role/extra-roles/remove` | 从分组中移除 |

## 交互说明

- 点击左侧角色节点，右侧刷新显示角色详情
- 新建角色时，如果当前选中了某个节点，自动将其作为父角色
- 删除角色前检查是否有关联用户，有则阻止并提示
- 复制角色会复制角色信息和所有权限配置，创建新角色
