# 权限排查

## 页面路径

`/audit/permission-view`

## 页面描述

排查用户的有效权限，按资源类型分维度展示权限来源、角色贡献和变更历史。是管理员排查权限问题的核心工具。

## Tab: 有效权限

调用 `permission-view/effective-permissions`

按资源类型分子 Tab 展示用户的所有有效权限：

- **🍃 菜单权限**：表格展示菜单资源 + 已授权操作码（VIEW/MANAGE），❌ 表示无权限
- **🔘 按钮权限**：按所属菜单分组，展示每个菜单下有权限/无权限的按钮
- **🔌 API 权限**：按所属服务分组，展示 ACCESS 操作码授权状态
- **📊 数据范围权限**：展示 DATA_READ / DATA_EDIT 操作码授权状态

## Tab: 近期变更

调用 `permission-view/recent-changes`

展示该用户相关角色的近期变更日志：
- 变更时间
- 变更人
- 变更类型（新增/修改/删除）
- 权限类型（菜单/按钮/API/数据范围）
- 变更摘要
- 可展开查看详细 diff

## Tab: 角色权限

调用 `permission-view/role-permissions`

选择某个角色，查看该角色的完整权限配置（同样按资源类型分 Tab 展示）。

## Tab: 资源用户

调用 `permission-view/resource-users`

选择某个资源，查看拥有该资源权限的所有用户列表。

## 交互说明

- 首先选择排查目标（用户或角色）
- 「有效权限」Tab 按资源类型分子 Tab，快速定位某类权限的情况
- 「单权限解释」先选资源类型再选具体资源，缩小排查范围
- 近期变更帮助判断「权限什么时候丢的」
