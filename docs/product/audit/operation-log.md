# 操作日志

## 页面路径

`/audit/operation-log`

## 页面描述

查看权限中心的操作日志，记录所有管理操作的审计信息。

## 表格列定义

| 列名 | 字段 | 说明 |
|------|------|------|
| 时间 | operateTime | yyyy-MM-dd HH:mm:ss |
| 操作人 | operatorName | 执行人名称 |
| 模块 | module | perm / user / system / integration |
| 动作 | action | CREATE / UPDATE / DELETE / GRANT / REVOKE / ASSIGN / SYNC 等 |
| 摘要 | summary | 操作简要描述 |
| 详情 | — | 查看详情按钮 |

## 搜索筛选

| 筛选项 | 类型 | 说明 |
|--------|------|------|
| 操作人 | 用户选择器 | 按操作人过滤 |
| 模块 | 下拉多选 | perm/user/system/integration |
| 动作 | 下拉多选 | CREATE/UPDATE/DELETE/GRANT/REVOKE/ASSIGN/SYNC |
| 时间范围 | 日期范围 | 开始时间-结束时间 |

## API 调用

| 操作 | API |
|------|-----|
| 查询日志 | `operation-log/list` |

## 交互说明

- 日志为只读，不支持修改或删除
- 「导出」按钮导出当前筛选条件下的日志数据
- 详情弹窗展示完整的请求参数和响应结果
- 时间范围默认最近 7 天
