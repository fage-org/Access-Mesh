# 变更日志

## 页面路径

`/audit/change-log`

## 页面描述

查看权限配置的变更记录，记录角色权限、资源权限等权限相关变更的详细 diff。

## 表格列定义

| 列名 | 字段 | 说明 |
|------|------|------|
| 时间 | changeTime | yyyy-MM-dd HH:mm:ss |
| 操作人 | operatorName | 变更执行人 |
| 实体类型 | entityType | abstract_role / resource_entity / role_permission 等 |
| 变更类型 | changeType | CREATE(绿) / UPDATE(蓝) / DELETE(红) |
| 摘要 | summary | 变更简要描述 |

## 搜索筛选

| 筛选项 | 类型 | 说明 |
|--------|------|------|
| 操作人 | 用户选择器 | 按操作人过滤 |
| 实体类型 | 下拉多选 | abstract_role / resource_entity / role_permission |
| 变更类型 | 下拉多选 | CREATE / UPDATE / DELETE |
| 时间范围 | 日期范围 | 开始时间-结束时间 |

## API 调用

| 操作 | API |
|------|-----|
| 查询变更日志 | `permission-change-log/list` |

## 交互说明

- 变更日志为只读，不支持修改或删除
- 变更类型用颜色区分：新增绿色、修改蓝色、删除红色
- Diff 展示以 + 和 - 前缀区分新增和删除的权限项
- 权限排查页面中的「近期变更」Tab 数据来源于此
- 时间范围默认最近 30 天
