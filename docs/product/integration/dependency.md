# 资源依赖

## 页面路径

`/integration/dependency`

## 页面描述

管理资源之间的依赖关系。当用户拥有资源 A 的权限时，自动获得依赖资源 B 的权限（DIRECT ∪ DEPENDENT 模型）。

## 表格列定义

| 列名 | 字段 | 说明 |
|------|------|------|
| 源资源 | sourceResourceCode | 需要依赖其他资源的资源 |
| 源类型 | sourceResourceType | 源资源类型 |
| 依赖资源 | targetResourceCode | 被依赖的资源 |
| 依赖类型 | dependencyType | REQUIRED / OPTIONAL |
| 操作 | — | 编辑、删除 |

## 新建/编辑依赖表单

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 源资源 | 资源选择器 | 是 | 需要依赖的资源 |
| 依赖资源 | 资源选择器 | 是 | 被依赖的资源 |
| 依赖类型 | 下拉 | 是 | REQUIRED / OPTIONAL |

## 依赖类型说明

| 类型 | 说明 |
|------|------|
| REQUIRED | 必需依赖 — 拥有源资源权限时自动获得依赖资源权限 |
| OPTIONAL | 可选依赖 — 依赖资源权限需要额外授予 |

## 批量同步

调用 `resource-dependency/batch-sync` 接口，根据资源层级关系自动推断依赖：

- 子按钮自动依赖其父级菜单
- API 资源自动依赖其关联的菜单资源

## 依赖图

调用 `resource-dependency/graph` 获取依赖关系图数据，以可视化方式展示：

```
┌─ 依赖关系图 ──────────────────────────────────────┐
│                                                    │
│  用户管理 ──→ 新增按钮                              │
│          ├──→ 编辑按钮                              │
│          ├──→ 删除按钮                              │
│          └──→ /api/admin/user/*                     │
│                                                    │
│  角色管理 ──→ 新增按钮                              │
```

## 循环依赖检查

- 点击「依赖图」前调用 `resource-dependency/check` 检查循环依赖
- 存在循环时高亮显示循环路径，并阻止新建会导致循环的依赖

## 交互说明

- 批量同步会自动创建命名规则推导出的依赖，不会删除已有手动依赖
- 删除依赖不影响资源实体本身
- 依赖关系在权限查询时自动生效（DIRECT ∪ DEPENDENT 模型）
