# 接口映射

## 页面路径

`/integration/api-mapping`

## 页面描述

管理资源的操作权限与 API 接口之间的映射关系。Gateway 鉴权时，根据请求的 API 路径和方法查找映射，判断用户是否拥有所需的操作权限。

例如：用户管理（菜单）的 VIEW 操作映射到 `POST /api/admin/user/list`，用户管理（菜单）的 MANAGE 操作映射到 `POST /api/admin/user/create`、`update`、`remove`。

## 表格列定义

| 列名 | 字段 | 说明 |
|------|------|------|
| 资源名称 | resourceName | 关联的资源实体名称 |
| 资源类型 | resourceType | MENU / API / DATA_SCOPE |
| 操作 | operationCode | 该资源上的操作权限（VIEW/MANAGE/ACCESS/DATA_READ/DATA_EDIT） |
| 接口路径 | apiPath | 完整的 API 路径 |
| HTTP方法 | httpMethod | POST / GET / PUT / DELETE |

## 新建/编辑映射表单

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 资源 | 资源选择器 | 是 | 选择目标资源实体 |
| 操作权限 | 下拉 | 是 | 根据资源类型动态展示可用操作（菜单: VIEW/MANAGE，API: ACCESS，数据范围: DATA_READ/DATA_EDIT） |
| 接口路径 | 文本 | 是 | 如 `/api/admin/user/list` |
| HTTP方法 | 下拉 | 是 | POST / GET / PUT / DELETE |
| 服务 | 下拉选择 | 是 | 关联的服务配置 |

## 映射规则说明

| 资源类型 | 可映射操作 | 典型映射 |
|---------|-----------|---------|
| MENU | VIEW, MANAGE | VIEW → 查询接口，MANAGE → 增删改接口 |
| API | ACCESS | ACCESS → 对应 API 接口 |
| DATA_SCOPE | DATA_READ, DATA_EDIT | DATA_READ → 数据查询接口，DATA_EDIT → 数据写入接口 |

## 交互说明

- 同一资源 + 操作可映射多个接口（一对多）
- 同一接口只映射一个资源 + 操作
- 「服务同步」时会自动创建映射，也可手动补充调整
- 删除映射不影响资源实体本身
- Gateway 鉴权流程：请求到达 → 根据接口路径+HTTP方法查找映射 → 得到资源+操作 → 检查用户是否拥有该操作权限
