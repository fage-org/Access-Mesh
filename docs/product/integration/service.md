# 服务管理

## 页面路径

`/integration/service`

## 页面描述

管理接入权限中心的外部服务配置，支持注册服务、同步接口、查看接口资源。

## 表格列定义

| 列名 | 字段 | 说明 |
|------|------|------|
| 服务编码 | serviceCode | 服务唯一标识 |
| 名称 | serviceName | 服务显示名称 |
| 基础路径 | basePath | API 路径前缀 |
| 接口数 | apiCount | 已同步接口数量 |
| 最后同步时间 | lastSyncTime | 最近一次同步时间 |
| 操作 | — | 详情、同步、编辑、删除 |

## 注册/编辑服务表单

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 服务编码 | 文本 | 是 | 唯一标识，创建后不可修改 |
| 服务名称 | 文本 | 是 | 显示名称 |
| 基础路径 | 文本 | 是 | API 路径前缀，如 `/api/admin` |
| 描述 | 文本域 | 否 | 服务说明 |

## 接口同步

### 全量同步流程

1. 调用 `service-config/sync` 接口，传入 `mode: "FULL"`
2. 后端扫描服务的所有接口
3. 返回 Diff 预览（新增/修改/删除的接口列表）
4. 用户确认后执行同步
5. 新接口自动创建为 API 类型的资源实体

### 增量同步

- 调用 `service-config/sync`，传入 `mode: "INCREMENTAL"`
- 只处理新增和变更的接口

## 交互说明

- 「同步」按钮触发全量同步，显示 Diff 预览后确认
- 同步完成后自动刷新接口列表
- 删除服务需确认，会级联删除该服务下的接口映射和资源
- 接口数通过 `service-config/apis` 查询
