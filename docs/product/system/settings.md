# 系统设置

## 页面路径

`/system/settings`

## 页面描述

管理权限中心的全局系统配置，如默认分页大小、缓存过期时间、权限默认策略等。

## 配置项说明

### 通用配置

| 配置项 | 键 | 类型 | 默认值 | 说明 |
|--------|---|------|--------|------|
| 默认分页大小 | defaultPageSize | 数字 | 20 | 列表默认每页条数 |
| 最大分页大小 | maxPageSize | 数字 | 200 | 单页最大条数限制 |
| 默认排序字段 | defaultSortField | 下拉 | createTime | 默认排序字段 |

### 权限配置

| 配置项 | 键 | 类型 | 默认值 | 说明 |
|--------|---|------|--------|------|
| 默认权限策略 | defaultConflictStrategy | 下拉 | ALLOW_UNION | 权限冲突时的默认仲裁策略 |
| 条件评估模式 | conditionEvalMode | 单选 | ALL_MATCH | 多条件时全部匹配/任一匹配 |
| 子权限默认类型 | defaultScopeType | 下拉 | scopeAll | 新建子权限时的默认类型 |

### 缓存配置

| 配置项 | 键 | 类型 | 默认值 | 说明 |
|--------|---|------|--------|------|
| L1 缓存过期时间 | l1CacheTtlSeconds | 数字 | 300 | Caffeine 本地缓存 TTL |
| L2 缓存过期时间 | l2CacheTtlSeconds | 数字 | 3600 | Redis 分布式缓存 TTL |
| 角色权限快照缓存 | rolePermSnapshotTtl | 数字 | 600 | 角色权限快照缓存时间 |

### 安全配置

| 配置项 | 键 | 类型 | 默认值 | 说明 |
|--------|---|------|--------|------|
| 登录失败锁定次数 | loginFailLockCount | 数字 | 5 | 连续失败次数 |
| 登录锁定时长 | loginLockMinutes | 数字 | 30 | 锁定时长 |
| Token 过期时间 | tokenExpireMinutes | 数字 | 120 | Token 有效期 |

## API 调用

| 操作 | API |
|------|-----|
| 查询所有配置 | `system-config/list` |
| 查询配置详情 | `system-config/detail` |
| 保存配置 | `system-config/save` |

## 交互说明

- 所有配置在同一个页面管理，分区展示
- 修改缓存配置后点击「清除全部缓存」使其立即生效
- 配置项修改后需点击「保存设置」提交
- 部分配置（如缓存 TTL）修改后需要等待旧缓存过期才能完全生效
