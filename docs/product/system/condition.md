# 权限条件

## 页面路径

`/system/condition`

## 页面描述

管理权限条件规则（PermissionCondition），在权限判定时附加上下文条件，如时间范围、IP 范围、部门限制等。

## 表格列定义

| 列名 | 字段 | 说明 |
|------|------|------|
| 条件名 | conditionName | 条件显示名称 |
| 编码 | conditionCode | 唯一编码 |
| 条件类型 | conditionType | TIME_RANGE / IP_RANGE / DEPT / REGION / CUSTOM |
| 规则 | rulePreview | 规则内容预览（截断显示） |
| 状态 | status | 启用/停用 |
| 操作 | — | 编辑、删除 |

## 新建/编辑条件表单

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 条件名 | 文本 | 是 | 1-100 字符 |
| 条件编码 | 文本 | 是 | 唯一编码 |
| 条件类型 | 下拉 | 是 | TIME_RANGE/IP_RANGE/DEPT/REGION/CUSTOM |
| 规则配置 | JSON编辑器 | 是 | 条件规则 JSON |
| 描述 | 文本域 | 否 | 条件说明 |
| 状态 | 开关 | 是 | 默认启用 |

## 规则类型说明

### TIME_RANGE（时间范围）

```json
{
  "type": "TIME_RANGE",
  "startTime": "09:00",
  "endTime": "18:00",
  "days": ["MON", "TUE", "WED", "THU", "FRI"]
}
```

### IP_RANGE（IP 范围）

```json
{
  "type": "IP_RANGE",
  "ranges": ["10.0.0.0/8", "192.168.1.0/24"]
}
```

### DEPT（部门限制）

```json
{
  "type": "DEPT",
  "deptIds": [1, 2, 3],
  "includeChildren": true
}
```

### CUSTOM（自定义）

```json
{
  "type": "CUSTOM",
  "expression": "context.region == 'CN' && context.level >= 3"
}
```

## 交互说明

- 条件编码创建后不可修改
- 规则配置使用 JSON 编辑器，带语法高亮和格式校验
- 条件类型切换时自动更新规则编辑器的模板
- 删除条件前需检查是否有角色引用，有则阻止
- 条件在权限判定时由 `ConditionEvalUtils` 评估
