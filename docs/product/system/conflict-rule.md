# 冲突规则

## 页面路径

`/system/conflict-rule`

## 页面描述

管理权限冲突规则（ConflictRule），定义当多个角色的权限产生冲突时的仲裁策略。

## 页面布局

├─────────────────────────────────────────────────────────┤

│ [搜索: 规则名] [策略 ▼] [🔍 查询] [↻ 重置]              │
│ [➕ 新建规则] [🔍 检测冲突]                               │
├─────────────────────────────────────────────────────────┤

## 表格列定义

| 列名 | 字段 | 说明 |
|------|------|------|
| 规则名 | ruleName | 规则显示名称 |
| 优先级 | priority | 数字越小优先级越高 |
| 仲裁策略 | strategy | DENY_WIN / ROLE_PRIORITY / TIME_PRIORITY |
| 范围 | scope | 全局 / 角色 / 条件 |
| 状态 | status | 启用/停用 |
| 操作 | — | 编辑、删除 |

## 新建/编辑规则表单

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 规则名 | 文本 | 是 | 1-100 字符 |
| 优先级 | 数字 | 是 | 1-100，越小越优先 |
| 仲裁策略 | 下拉 | 是 | DENY_WIN/ROLE_PRIORITY/TIME_PRIORITY |
| 适用范围 | 配置区 | 是 | 全局/指定角色/指定条件 |
| 描述 | 文本域 | 否 | 规则说明 |
| 状态 | 开关 | 是 | 默认启用 |

## 仲裁策略说明

| 策略 | 说明 |
|------|------|
| DENY_WIN | 拒绝优先 — 任意角色 DENY 则最终 DENY |
| ROLE_PRIORITY | 角色优先级 — 按角色类型的优先级仲裁 |
| TIME_PRIORITY | 时间优先 — 按授权时间，最近的授权优先 |

## 检测冲突

点击「检测冲突」按钮调用 `conflict-rule/detect`：

```
┌─ 冲突检测结果 ──────────────────────────────────────────┐
│                                                          │
│ 扫描范围: 全部角色                                       │
│ 扫描结果: 发现 3 组冲突                                  │
│                                                          │
│ ┌─ 冲突 1 ──────────────────────────────────────────┐   │
│ │ 资源: 用户管理 (菜单) → MANAGE                     │   │
│ │ 角色 A: 管理员 → ALLOW                             │   │
│ │ 角色 B: 安全审计 → DENY                            │   │
│ │ 当前仲裁: DENY_WIN → 最终 DENY                    │   │
│ └────────────────────────────────────────────────────┘   │
│                                                          │
│ ┌─ 冲突 2 ──────────────────────────────────────────┐   │
│ │ 资源: 角色管理 (菜单) → VIEW                       │   │
│ │ 角色 A: 管理员 → ALLOW                             │   │
│ │ 角色 B: 研发组 → DENY                              │   │
│ │ 当前仲裁: DENY_WIN → 最终 DENY                    │   │
│ └────────────────────────────────────────────────────┘   │
│                                                          │
│ 共 3 组冲突  [关闭]                                      │
└─────────────────────────────────────────────────────────┘
```

## 交互说明

- 规则按优先级排序，优先级高的规则先执行
- 「检测冲突」扫描当前所有角色的权限配置，找出潜在冲突
- 检测结果展示冲突资源、涉及角色和当前仲裁结果
- 删除规则需确认，会影响权限判定结果
