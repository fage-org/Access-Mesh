# 业务域

## 页面路径

`/system/biz-domain`

## 页面描述

管理业务域（BizDomain），业务域是权限管理的逻辑分区，每个租户有且仅有一个全局域，可创建多个业务域。

## 表格列定义

| 列名 | 字段 | 说明 |
|------|------|------|
| 域名 | domainName | 业务域显示名称 |
| 编码 | domainCode | 唯一编码 |
| 全局 | global | 是否为全局域（每租户仅一个） |
| 描述 | description | 业务域说明 |
| 创建时间 | createTime | 创建时间 |
| 状态 | status | 启用/停用 |
| 操作 | — | 编辑、配置、删除 |

## 新建/编辑业务域表单

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 域名 | 文本 | 是 | 1-100 字符 |
| 编码 | 文本 | 是 | 唯一编码，创建后不可修改 |
| 描述 | 文本域 | 否 | 域说明 |
| 状态 | 开关 | 是 | 默认启用 |

## 域配置入口

每个业务域有一个「配置」按钮，点击跳转到 `/system/domain-config?domainCode=xxx`，管理该域的规则配置。

## 全局域说明

- 每个租户有且仅有一个全局域（`global = true`）
- 全局域不可删除
- 全局域的范围隐式包含未被其他域认领的资源类型
- 全局域为默认查询范围，对应不传 `domainCode` 时的数据可见性

## 交互说明

- 全局域的「删除」按钮禁用
- 删除业务域前需检查是否有关联配置，有则阻止
- 新建业务域后需进入「域配置」设置允许的类型范围
