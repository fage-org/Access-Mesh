# 域配置

## 页面路径

`/system/domain-config`

## 页面描述

管理业务域的规则配置，定义每个域允许的角色类型、资源类型、操作码和子权限类型。

## 配置项说明

### 角色类型 (CLASSIFY)

定义该域可创建的角色类型。只有配置的角色类型才能在该域下创建。

| API | 说明 |
|-----|------|
| `domain-config/list` | 查询域的 CLASSIFY 配置列表 |
| `domain-config/save` | 保存配置 |
| `domain-config/remove` | 删除配置项 |

### 资源类型 (CLASSIFY)

定义该域可创建的资源类型。

### 操作码

定义该域内授权时可用的操作码范围。

### 子权限类型

定义该域支持的子权限维度（scopeAll、scopeCustom、scopeDept 等）。

## API 调用

| 操作 | API |
|------|-----|
| 查询域配置 | `domain-config/list?domainCode=xxx` |
| 查询域详情 | `domain-config/detail?domainCode=xxx` |
| 保存配置 | `domain-config/save` |
| 删除配置 | `domain-config/remove` |

## 交互说明

- 每个配置区域独立保存
- 添加配置项时从类型定义中选择（过滤已添加项）
- 全局域的 CLASSIFY 配置影响全局范围
- 保存成功后配置立即生效
- 支持 URL 参数 `?domainCode=xxx` 直接定位到某个域的配置
