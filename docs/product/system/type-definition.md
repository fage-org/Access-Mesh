# 类型定义

## 页面路径

`/system/type-definition`

## 页面描述

管理权限中心的类型定义（TypeDefinition），包括用户类型、角色类型、资源类型、主体类型等。类型定义是权限模型的基础元数据。

## 表格列定义

| 列名 | 字段 | 说明 |
|------|------|------|
| 类型名 | typeName | 类型显示名称 |
| 类型编码 | typeCode | 唯一编码 |
| 分类 | category | system / user / role / resource / subject / operation |
| 值 | typeValue | 类型对应的整数值 |
| 状态 | status | 启用/停用 |
| 操作 | — | 编辑、删除 |

## 新建/编辑类型表单

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 类型名 | 文本 | 是 | 1-100 字符 |
| 类型编码 | 文本 | 是 | 唯一编码，创建后不可修改 |
| 分类 | 下拉 | 是 | system/user/role/resource/subject/operation |
| 值 | 数字 | 是 | 整数，同分类下唯一 |
| 描述 | 文本域 | 否 | 类型说明 |
| 状态 | 开关 | 是 | 默认启用 |

## 预设类型

### 角色类型 (role_type)

| 编码 | 值 | 说明 |
|------|---|------|
| BASIC | 1 | 基础角色 |
| ORG | 2 | 组织角色 |
| GROUP_ROLE | 3 | 分组角色 |
| POSITION | 4 | 职位角色 |
| PERSONAL | 5 | 个人角色 |

### 资源类型 (resource_type)

| 编码 | 值 | 说明 |
|------|---|------|
| MENU | 1 | 菜单 |
| BUTTON | 2 | 按钮 |
| API | 3 | API 接口 |
| DATA_SCOPE | 4 | 数据范围 |

## 交互说明

- 类型定义是系统级基础配置，修改需谨慎
- 已被引用的类型禁止删除（如已创建该类型的角色或资源）
- 分类筛选支持多选
- 删除前检查引用，有引用时阻止并提示
