# 公共组件规格

本文档定义管理控制台中跨页面复用的公共组件交互规格。

## 资源选择器

用于在表单中选择资源实体。

```
┌─ 选择资源 ─────────────────────────┐
│ 资源类型: [MENU ▼]                 │
│ 编码类型: [default]                │
│ 搜索: [🔍 sys:user]                │
│                                    │
│ ┌──────────────────────────────┐   │
│ │ ☑ sys:user — 用户管理        │   │
│ │ ☐ sys:org — 组织管理         │   │
│ │ ☐ sys:role — 角色管理        │   │
│ └──────────────────────────────┘   │
│                                    │
│           [取消]  [确认]           │
└────────────────────────────────────┘
```

## 操作码选择器

根据资源类型动态过滤可选操作码。

```
┌─ 选择操作 ──────────┐
│ ☑ VIEW              │
│ ☑ MANAGE            │
│ ☐ DATA_READ         │
│ ☐ DATA_EDIT         │
│ ☐ ACCESS            │
└─────────────────────┘
```

## JSON 编辑器

用于条件规则、域配置值等 JSON 字段编辑。

- 语法高亮
- 格式校验
- 格式化/压缩按钮
- 错误行标记

## 树形组件通用规格

所有树形组件（角色树、资源树、组织树）共享以下交互：

| 功能 | 说明 |
|------|------|
| 搜索过滤 | 输入关键词实时过滤节点，高亮匹配文字 |
| 懒加载 | 大数据量时按需加载子节点 |
| 右键菜单 | 新建子节点、编辑、移动、删除、启停 |
| 拖拽排序 | 支持拖拽调整同层级顺序 |
| 展开/折叠 | 全部展开/全部折叠按钮 |
| 多选 | 支持 checkbox 多选 |
| 节点图标 | 按类型显示不同图标 |
