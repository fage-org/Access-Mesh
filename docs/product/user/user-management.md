# 用户管理

## 页面路径

`/user`

## 页面描述

左侧组织树，右侧用户列表。组织详情和用户详情均通过弹窗展示，无需跳转页面。

## 左侧：组织树

| 功能 | 说明 |
|------|------|
| 搜索过滤 | 输入关键词过滤节点，高亮匹配 |
| 点击节点 | 右侧用户列表自动按该组织过滤 |
| 右键菜单 | 新建子组织、编辑、移动、删除、启停用 |
| 拖拽排序 | 支持拖拽调整层级和顺序 |
| 新建根节点 | 底部「+ 新建」按钮 |
| 展开/折叠 | 全部展开 / 全部折叠 |
| 成员数标记 | 节点旁显示成员数量 Badge |

### 新建/编辑组织弹窗

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 名称 | 文本 | 是 | 1-100 字符 |
| 编码 | 文本 | 是 | 字母数字下划线，唯一 |
| 上级组织 | 树形选择 | 否 | 空表示根节点 |
| 排序 | 数字 | 是 | 默认 0，越小越靠前 |
| 负责人 | 用户选择器 | 否 | 选择负责人 |
| 状态 | 开关 | 是 | 默认启用 |

## 右侧：用户列表

### 表格列定义

| 列名 | 字段 | 说明 |
|------|------|------|
| 勾选 | checkbox | 批量操作 |
| 用户名 | username | 主键标识 |
| 姓名 | realName | 显示名称 |
| 手机号 | phone | 脱敏显示 138****1234 |
| 状态 | status | 🟢启用 / 🔴停用 |
| 操作 | — | 详情、编辑、分配角色、启停用、删除 |

### 搜索筛选

| 筛选项 | 类型 | 说明 |
|--------|------|------|
| 关键词 | 文本输入 | 匹配用户名或姓名 |
| 状态 | 下拉选择 | 启用/停用/全部 |
| 组织 | 隐式 | 由左侧组织树节点选中状态决定，点击节点自动过滤 |

### 操作按钮

| 按钮 | 行为 |
|------|------|
| 新建用户 | 打开新建表单弹窗 |
| 批量导入 | 打开导入弹窗 |
| 同步到权限中心 | 调用 `abstract-user/sync`，成功后刷新列表 |
| 详情 | 打开用户详情弹窗 |
| 编辑 | 打开编辑表单弹窗 |
| 分配角色 | 跳转 `/permission/user-role?userId=xxx` |
| 启停用 | 确认弹窗后切换状态 |
| 删除 | 二次确认后软删除 |

### 新建/编辑用户弹窗

| 字段 | 类型 | 必填 | 验证规则 |
|------|------|------|---------|
| 用户名 | 文本 | 是 | 3-32 位字母数字 |
| 姓名 | 文本 | 是 | 1-50 字符 |
| 手机号 | 文本 | 否 | 11 位手机号格式 |
| 邮箱 | 文本 | 否 | 邮箱格式 |
| 所属组织 | 树形选择 | 否 | 从组织树选择 |
| 状态 | 开关 | 是 | 默认启用 |

- 点击「查看详细权限排查」跳转到 `/audit/permission-view?userId=xxx`

## 交互说明

- 左侧点击组织节点，右侧列表自动按该组织过滤；点击空白处或「全部」显示所有用户
- 「同步到权限中心」调用后端 `abstract-user/sync` 接口，将 admin-service 用户数据同步到 permission-center
- 批量删除需二次确认弹窗，显示将删除的用户数量
- 删除组织需确认，如有关联成员则提示「请先移除成员」
- 停用组织时，其下级组织一并停用（需确认）
- 列表支持按列排序（点击表头切换升/降序）
- 用户详情弹窗中「分配角色」跳转 `/permission/user-role?userId=xxx`
- 「回收」角色需二次确认，调用 `user-role/revoke` 接口
