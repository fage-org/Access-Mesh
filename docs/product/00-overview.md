# 系统概述

## 产品定位

AccessMesh 是一个企业级多租户权限管理平台，管理控制台是管理员和运维人员的统一操作入口。系统支持：

- **多租户隔离**：所有数据按租户隔离，管理员在登录时绑定租户
- **多业务域**：通过业务域（Domain）对角色、资源进行分区管理
- **灵活角色模型**：支持组织角色、职位角色、个人角色、分组角色、基础角色五种类型
- **细粒度权限**：菜单/按钮/API/数据范围四级权限控制
- **权限排查**：可视化解释用户权限来源和变更历史

## 技术栈

- **前端框架**：Vue 3 + TypeScript + Element Plus + Tailwind CSS
- **路由**：Vue Router（动态路由，登录后按权限加载菜单）
- **状态管理**：Pinia
- **HTTP**：Axios（统一 POST + JSON Body）
- **图标**：Iconify

## 全局交互规范

| 规范项 | 说明 |
|--------|------|
| 接口方式 | 所有接口统一 POST + JSON Body |
| 响应结构 | `{ code: 200, message: "success", data: {}, requestId, traceId }` |
| 分页 | 入参 `pageNum/pageSize/sort`，响应 `items/total/pageNum/pageSize/hasNext` |
| 列表包装 | 所有列表响应在 `data.items` 中，即使是非分页列表 |
| 删除操作 | 统一使用 `{ ids: [...] }` 批量软删除 |
| 租户 | 从 Header `X-Tenant-Id` 读取，前端无需在表单中传 tenantId |
| 错误提示 | `code !== 200` 时显示 `message` 字段内容 |
| 业务域 | 通过左侧菜单参数切换，选中菜单项时携带 `domainCode`，影响当前页面的数据过滤范围 |
