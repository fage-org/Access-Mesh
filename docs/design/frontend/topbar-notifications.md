# 顶栏通知入口边界

## 目标与交付状态

2026-10-18 确认：移除未接入真实通知的铃铛及无消费者模板代码，不保留“暂无消息”或“未接入”空入口。由 [T-FE-077](../../archive/2026-10-18/tasks/T-FE-077.md) 实施：三种布局均已移除入口及专用模板代码。

原 `lay-notice` 的硬编码消息、红点和专用组件已删除。竖向 `lay-navbar/index.vue`、横向 `NavHorizontal.vue`、混合 `NavMix.vue` 不再挂载通知入口。后台公告 API 未因此退役。

## 页面与组件边界

- 三种导航都移除铃铛、红点及下拉内容，保留邻接的搜索、全屏、用户操作与布局切换。
- 删除 `lay-notice` 中仅服务于该入口的组件、类型、示例数据和专用样式；删除前复核全仓消费者，发现真实复用则保留被复用部分并核实范围。
- 不添加显示开关，不将示例内容换成另一组假数据，不新增通知轮询、推送、未读计数或消息中心。
- 后台公告能力保持；未来接入真实公告或其他通知须另行定义受众、读取与已读语义，不能把删除模板解释为公告能力退役。

## 验证边界

三种导航实际页面确认入口消失、布局与其他操作正常；检索 `LayNotice`、`header-notice`、`noticesData` 及示例文本，确认无活跃残留。纯删除不新增只检查源字符串的测试；执行前端类型、lint 与构建检查，结合本计划统一验收。
