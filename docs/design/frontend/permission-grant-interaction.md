# 权限授予 交互规格（重构提案）

> 本文为 [`permission-grant.md`](./permission-grant.md) 的交互重构提案，基于 [`permission-grant-state-model.md`](./permission-grant-state-model.md) 重新设计表单交互。可自由发挥，与现有 §16 交互不同。
>
> 依赖状态模型：D1–D6 六正交维度 + 单一事实源（baseline + grantTasks replay）。
> 不破坏状态模型不变量，仅改变触发方式。

## 0. 对现有交互的诊断

现有 §16 "中栏只读摘要 + 四步授权弹窗 + 右栏变更" 的痛点（作为重构动机）：

| # | 痛点 | 根因 |
|---|---|---|
| P1 | 单项授权过载：给一个资源加一个操作也要走 4 步弹窗 | 单项与批量共用同一重型弹窗 |
| P2 | 中栏与编辑割裂：树上看到资源，却要打开弹窗重新选操作/资源 | 中栏被设计成只读，编辑权交给弹窗 |
| P3 | 资源与操作分两步选，割裂"给 X 加 VIEW"的心智 | 步骤线性化拆分了原子意图 |
| P4 | 条件/canGrant 强制第三步，90% 场景为空 | 渐进披露不足，低频属性占用固定步骤 |
| P5 | 子权限强制第四步，多数为空状态 | 同 P4 |
| P6 | R11"冗余直接记录"开关藏在第三步，用户感知不到代价 | 关键决策被步骤吞没 |
| P7 | 编辑在弹窗、撤销在右栏，跨容器心智不连贯 | 编辑与变更视图分离 |
| P8 | 无实时 diff：确认后才进右栏，"试错成本"高 | 变更非即时投影 |
| P9 | 保存失败多子态恢复路径分散 | 失败语义未在矩阵上就地表达 |

## 1. 设计理念

**直接操作矩阵 + 渐进披露 + 实时变更流**。把编辑权还给中栏，弹窗降级为"批量与复杂场景"的可选入口，而非唯一路径。

| 原则 | 实现 |
|---|---|
| 所见即所编辑 | 资源×操作矩阵单元格点击即切换，不经过弹窗 |
| 渐进披露 | 默认只暴露授予/撤销；条件/canGrant/子权限由副标记触发就地展开 |
| 批量即多选 | 框选/Ctrl/Shift 多选单元格 -> 浮出批量工具栏，就地配置 |
| 变更实时投影 | 右栏 diff 随每次操作即时更新，撤销/编辑/定位就地 |
| 保存前总览 | 保存前 bottom-sheet 列变更 + 警告，明确"将变更 N 项" |

## 2. 布局

```
┌─ 上下文条：业务域 / 当前角色 / 只读标记 / 未保存 N ────────────────────────────┐

│ │ 角色树        │ │ ┌批量工具栏（选中时浮出）──────────┐│ │ 新增/修改/移除   │ │

│ │              │ │ └──────────────────────────────────┘│ │                │ │
│ │              │ │ 资源          VIEW   CREATE  UPDATE │ │ 警告区          │ │
```

- 中栏是主编辑区，常驻可编辑矩阵。
- 授权弹窗**保留但降级**为"批量入口"（资源类型标题区"批量授权"按钮）和"复杂子权限批量"的可选路径；日常单项/小批量全部在矩阵就地完成。

## 3. 状态机（复用并细化状态模型）

复用 [`permission-grant-state-model.md`](./permission-grant-state-model.md) 的 D1–D6。新增/细化以下交互态：

### 3.1 单元格交互态（D4 扩展）

单元格在 6 态 `CellState` 之上增加 **交互子态**（正交于有效态）：

| 交互子态 | 触发 | 含义 |
|---|---|---|
| `IDLE` | 默认 | 静态展示 |
| `HOVER` | 鼠标悬停 / 键盘聚焦 | 露出副标记图标 + 操作提示 |
| `PENDING_TOGGLE` | 点击后到投影更新前 | 极短，乐观更新前瞬态（见 §4.2） |
| `INLINE_CONFIG_OPEN` | 点击副标记 | 该行就地展开附加设置，或 popover 锚定 |
| `BATCH_SELECTED` | 被纳入批量多选 | 蓝色描边 + 角标 |
| `CONFLICT_HIGHLIGHT` | 保存前总览命中警告 | 黄色描边 + 角标链接到总览 |
| `SAVE_FAILED_MARK` | 保存失败涉及该格 | 红色描边 + 重试图标 |

### 3.2 批量态（D5 扩展）

| 态 | 进入 | 退出 |
|---|---|---|
| `BATCH_IDLE` | 默认 | 多选 >=1 |
| `BATCH_ACTIVE` | 多选 >=1 单元格 | 清除选择 / ESC / 保存 |
| `BATCH_CONFIG_OPEN` | 批量工具栏点"条件/转授权" | 关闭侧拉 / ESC |

### 3.3 保存前总览态（D5 细化 SAVE 子态）

`SAVING` 拆为：

```
DIRTY ──点击保存──► SAVE_PREVIEW（bottom-sheet 总览）──确认──► SAVING（请求中）──► CLEAN/SAVE_FAILED/STALE
                          │
                          └──取消──► DIRTY
```

`SAVE_PREVIEW` 是新增的中间态：保存前强制展示变更总览 + 警告，用户确认后才真正发请求。解决 P6/P8（试错成本与决策可见性）。

## 4. 微交互规格

### 4.1 单元格点击切换（核心，解决 P1/P2/P3）

**触发**：点击单元格主区域（权限符号区）。

**规约（方案 A 多条件分支模型）**：单元格主区域点击 = **聚合行为**，不直接移除单条授权（一单元格可能有多条 OR 分支）。
- `UNAUTHORIZED` + grantableByOperator -> 新增无条件分支（PENDING_ADD），符号 `·` -> `＋`（待保存绿）。
- `UNAUTHORIZED` + NOT_GRANTABLE -> 不变，tooltip 显示 denyReason，无视觉跳变。
- 有授权分支（GRANTED/CONDITIONAL，一条或多条）-> 点击主区域**展开分支列表**（见 §4.2），不直接移除；移除须在分支列表中按具体 GrantVariantId 执行。
- `PENDING_ADD`（单条待新增分支）-> 撤销该分支，若无其他分支则回到 `UNAUTHORIZED`。
- `PENDING_REMOVE`（某分支待移除）-> 恢复该分支。
- `MODIFIED` -> 点击主区域展开分支列表，按变体恢复属性修改（恢复该变体 baseline 的 conditionCode/canGrant）。
- `ALL_COVERED`（实例单元）-> 点击展开分支列表；移除被 ALL 覆盖的直接分支提示"不影响 ALL 覆盖"；无直接分支则提示"由 ALL 覆盖，去 ALL 行调整"并跳转。
- `INHERITED` -> 只读（被同角色其他操作 effectiveBits 覆盖，如 MANAGE 覆盖 VIEW），点击展示来源操作并提供"跳转来源操作"，不可直接授予/移除。精确建模依赖 T-PERM-034，当前不可达。
- `DERIVED` -> 只读，点击展示来源，不可切换。
- `SAVING` / `READONLY` -> 点击无效，矩阵整体禁用光标。

> **方案 A 关键**：单元格是分支聚合，主区域点击展开分支列表而非直接切换；新增/编辑/撤销均按具体 GrantVariantId（permissionId 或临时 UUID）操作。

**反馈**：
- 乐观投影：点击即更新本地投影（mainDraft computed 重算），符号瞬时切换，无 loading（本地操作无网络）。
- 触觉/声音：无（企业后台，避免噪音）。
- 右栏 diff 即时 +1/-1，底部计数即时更新。

### 4.2 单元格副标记就地配置（解决 P4/P6）

**触发**：点击单元格上的副标记图标（◑条件 / ↗转授权 / ⌗子权限）。

**规约（多条件分支列表）**：
- 点击 ◑/↗ 或单元格主区域 -> 该单元格**下方就地展开分支列表**（row-span 展开，非弹窗），列出该 PermCellKey 下所有 OR 分支，每分支一行：
  - 分支标识（无条件 / 条件名）+ `ReConditionPicker`（编辑该分支 conditionCode，supportsCondition=false 时隐藏）+ `canGrant` switch（supportsDelegation=false 时隐藏）+ "撤销此分支"（按 GrantVariantId 移除该分支）
  - 每分支独立编辑/撤销，互不影响（方案 A：不同 conditionCode 是独立 OR 分支）
- 列表底部"+ 添加分支"按钮：新增一条 OR 分支（默认无条件或选条件）；同 `PermCellKey + conditionCode` 重复**前端就地阻断**（见 state §2.2 P1-2 第4点）
- 未授权单元格：副标记不显示；"授予并配置"快捷（hover `＋` 长按 / 右键"授予并配置"）一步新增分支 + 展开列表
- R11 冗余决策**前置到单元格**：对"被 ALL 覆盖且无直接记录"的实例单元新增分支时，列表内警告"该操作已被 ALL 覆盖，创建直接记录冗余"，提供"跳过（推荐）"/"仍创建"。不再藏在第三步开关。

**规约（子权限 ⌗）**：见 §4.4。

**反馈**：
- 展开行用 `max-height` 过渡动画（见 §5），不顶起整树滚动。
- 同一时刻同一资源类型下只能展开一个单元格的配置行（单焦点），展开新行自动收旧行。
- `ESC` 收起当前展开行并保留已改值（草稿不丢）。

### 4.3 批量多选与工具栏（解决 P1 批量、P3）

**触发多选**：
- `Ctrl+点击` 单元格：加入/移出选择集。
- `Shift+点击`：矩形范围选择（同操作列连续资源，或同资源连续操作）。
- `拖拽框选`：在矩阵上拖出选框，框内单元格入选。
- 资源行头 `Ctrl+点击`：整行所有操作入选；操作列头 `Ctrl+点击`：整列所有资源入选。
- ALL 行 / 派生 / 不可授予单元格：不可入选（点击不响应或灰态）。

**批量工具栏（选中 >=1 浮出，锚定矩阵顶部 sticky）**：

```
已选 3 个单元 │ 授予全部 │ 撤销全部 │ 设置条件… │ 设置转授权… │ 清除选择
```

- "授予全部"：选择集内所有 UNAUTHORIZED+grantable -> PENDING_ADD；已有授权的不变。
- "撤销全部"：选择集内所有有直接记录 -> PENDING_REMOVE。
- "设置条件…"：打开**侧拉面板**（右侧 drawer），为选择集每个单元格**新增一条统一条件 OR 分支**（add，不修改既有分支）；面板显示选择集预览 + 统一 conditionCode + 重复检测（同单元格同条件已存在则阻断）。**修改既有分支须在单元格分支列表逐分支操作**（非批量，因批量无法指定具体 GrantVariantId）。若选择集跨操作，面板提示"将为全部选中单元格新增同一条件分支；如需分别配置请拆分操作"。
- "设置转授权…"：统一 canGrant **作用于本次新增分支**；批量修改既有分支的 canGrant 不支持（须逐分支编辑）。
- "清除选择" / `ESC`：退出批量态，选择集清空，工具栏收起。

**批量与单项统一**：批量工具栏的"设置条件"侧拉面板 = 单项就地展开行的放大版，同一组件不同尺寸。不再有独立四步弹窗承担批量。

### 4.4 子权限矩阵内展开（解决 P5）

**触发**：分支列表中父变体行的 `⌗ 子权限` 按钮（T-FE-033 Q2 决策：多条件模型下子权限 `dependOn` 具体父变体 GrantVariantId，非 PermCellKey；单元格 `⌗` 仅作"存在子权限"聚合标记与展开提示，不承担子权限归属）。

**规约**：
- 父变体行**向下展开子矩阵**（同一矩阵的嵌套层，缩进显示，只一层），列变为子资源类型×操作；多个子资源类型用 tab 切换（Q3=A）。
- 子权限单元格交互同主权限（点击切换 / 副标记就地配置）。
- 只展开一层（不变量：子权限不再有范围入口）。
- 删除主权限时，展开的子行先变灰 + 标记"将级联移除 N 项"，确认在保存前总览（见 §4.5）。
- 子权限的父权限因 R11 未进投影时，子矩阵行隐藏 + 提示"父权限未生效，子权限不可配"。

**反馈**：展开用 `expand-row` 过渡，子矩阵背景微深一级（`--el-fill-color-light`）区分层级。

### 4.5 保存前总览 bottom-sheet（解决 P6/P8/P9）

**触发**：点击底部"保存"按钮。

**规约**：从底部滑出 sheet（不遮罩全屏，留矩阵上半部可见），分三区：
1. **变更清单**：按 新增/修改/移除/子权限 分组列出，每项可点定位回矩阵。
2. **警告区**（如有）：
   - 冗余直接记录："3 项被 ALL 覆盖，创建直接记录冗余，建议移除 [全部移除] [保留]"
   - 级联删除："移除 X 将级联移除其 2 项子权限"
   - 冲突（未来）："此授权与冲突规则 X 互斥，运行时将被抑制"
3. **确认栏**："确认保存 5 项变更" / "取消"。

**规约（失败恢复，解决 P9）**：保存失败后，sheet 不立即关闭，切到"失败视图"：
- `CHILD_PARTIAL`：标红失败子项，"主权限已保存；2 项子权限失败 [重试失败项] [保留草稿]"。
- `MAIN_FAILED`：全部标红，"保存失败：<原因> [重试] [关闭]"，草稿完整保留（业务拒绝，服务端未提交，可安全重试）。
- `SAVE_OUTCOME_UNKNOWN`：sheet 提示"保存请求未确认结果（网络超时/断网），正在重新拉取事实核对…"，矩阵置灰，**禁止直接重试**；自动执行 fetchBaseline+reconcile，完成后告知"已落库 N 项，未落库 M 项 [续传 M 项] [放弃]"。
- `RELOAD_FAILED` -> STALE：sheet 提示"保存已提交但事实刷新失败，请重新选角色"，矩阵置灰。
- `STALE_WITH_CHILD_FAILURE`：sheet 同时提示"事实已过期，且 N 项子权限待重试 [一键刷新并重试] [仅刷新]"，按原子恢复流程执行（见 error-flow §2.5）。

### 4.6 右栏变更流（解决 P7/P8）

**规约**：
- 实时 diff（allDiff computed），随矩阵操作即时更新，无需"确认加入"。
- 每项支持：点定位（中栏展开+聚焦该格）、逐项撤销（移除对应 grantTask 或回滚单元格）。
- 任务粒度撤销（T-FE-028）：按 grantTask 分组显示"一次批量操作产生的 N 项"，可整组撤销。
- 警告区与保存前总览联动：右栏警告角标 = 总览警告预览。
- 底部"放弃全部"/"保存全部"常驻；`hasDraft=false` 时保存禁用 + "已同步"。

## 5. 动效规格

遵循 `animation-principles`：目的性、克制、不阻塞。

| 场景 | 动效 | 时长/曲线 |
|---|---|---|
| 单元格符号切换 | 旧符号 fade-out 20ms -> 新符号 scale 0.8->1 + fade-in | 120ms ease-out |
| 就地配置行展开 | `max-height` 0->auto + opacity 0->1 | 160ms ease-out |
| 子权限矩阵展开 | 行高展开 + 子行 stagger fade-in（每行延迟 20ms，最多 5 行不延迟） | 180ms |
| 批量工具栏浮出 | translateY -8->0 + opacity | 140ms ease-out |
| 选中描边 | 描边即时 + 角标 scale-in | 100ms |
| 右栏 diff 项进入 | slide-in from right 8px + fade | 120ms |
| 保存前 sheet 滑出 | translateY 100%->0 | 200ms ease-out |
| 保存中进度 | 顶部线性进度条 indeterminate | - |
| 失败标红 | 描边 color 过渡 + 抖动 1 次（4px, 200ms） | 220ms |

**减少动效**：`prefers-reduced-motion: reduce` 时所有过渡 <= 1ms 或禁用抖动。

## 6. 手势与键盘

### 6.1 键盘（可访问性核心）

| 键 | 行为 |
|---|---|
| `Tab` / `Shift+Tab` | 在单元格间移动焦点（资源->操作列方向） |
| `Enter` / `Space` | 切换当前聚焦单元格授权 |
| `Ctrl+Enter` | 打开当前格就地附加设置 |
| `Ctrl+Shift+Enter` | 打开当前格子权限矩阵 |
| `Ctrl+点击` | 多选（鼠标） |
| `Shift+方向键` | 扩展选择 |
| `Esc` | 收起就地配置 / 退出批量 / 关闭 sheet（取消） |
| `Ctrl+S` | 触发保存前总览 |
| `Ctrl+Z` | 撤销最近一次操作（任务粒度，T-FE-028） |
| `Ctrl+D` | 放弃全部（需二次确认） |

### 6.2 指针/触控

- 桌面：hover 露副标记；点击主区切换；点击副标记展开。
- 触屏：无 hover，单元格常驻显示副标记小图标（触屏检测 `deviceDetection`）；长按单元格 = 右键菜单（授予并配置 / 移除 / 附加设置 / 定位）。
- 拖拽框选：仅桌面指针；触屏用"长按进入多选模式 + 点选"。

## 7. 反馈规格

| 事件 | 反馈 | 通道 |
|---|---|---|
| 授予/撤销 | 符号即时切换 + 右栏 diff +1/-1 + 底部计数更新 | 视觉 |
| 不可授予点击 | tooltip denyReason + 单元格轻微 shake（1 次） | 视觉 |
| 条件保存停用 | 就地配置行 picker 标红"条件已停用，请替换" | 视觉 |
| 批量授予部分被拒 | 工具栏 toast"3 项已授予，2 项不可授予已跳过" | 视觉 |
| 保存前总览警告 | sheet 警告区黄色 alert + 相关矩阵格 CONFLICT_HIGHLIGHT 黄描边 | 视觉 |
| 保存成功 | toast success + 矩阵回到 CLEAN 态（符号稳态）+ sheet 滑出 | 视觉 |
| 保存失败 | sheet 失败视图 + 失败格红描边 + toast error | 视觉 |
| STALE | 矩阵置灰 + 顶部 banner"事实已过期，重新选角色" | 视觉 |
| 离开有草稿 | 路由 confirm / beforeunload 拦截 | 模态 |

**反馈原则**：本地操作（投影变更）无 toast（靠视觉即时反馈，避免噪音）；跨网络操作（保存/重载）有 toast；警告/失败必有文字说明 + 可恢复动作。

## 8. 错误流

错误处理详见 [`permission-grant-error-flow.md`](./permission-grant-error-flow.md)。本文仅列交互层错误态：

- 就地阻断：条件停用 / 子权限类型不符 / 不可授予 -> 单元格标红或灰态。
- 保存前警告：SAVE_PREVIEW sheet 警告区（冗余/级联/冲突）。
- 保存失败：sheet 失败视图（CHILD_PARTIAL / MAIN 两子态 + SAVE_OUTCOME_UNKNOWN/STALE 顶层态 + STALE_WITH_CHILD_FAILURE 组合态）。
- 加载错误：栏级 skeleton -> empty + 重试，不影响其他栏。

## 9. 加载状态

| 场景 | 加载态 |
|---|---|
| 首次进页面 | 左栏角色树 skeleton；中右栏 empty"请选择角色" |
| 选角色加载事实 | 中栏矩阵保持上一角色骨架灰态 + 顶部细进度条；失败回退旧上下文 |
| 切资源类型 | 矩阵区 skeleton（保留左栏角色树） |
| 单元格操作 | 无 loading（本地投影即时） |
| 保存 | 矩阵整体置灰 + 顶部 indeterminate 进度条 + 底部按钮 loading |
| 重载 baseline | 同保存 |
| 条件候选懒加载 | picker 下拉显示"加载中…" |

**原则**：本地操作绝不显示 loading（避免伪延迟）；网络操作用骨架/进度条而非全屏 spinner，保留上下文。

## 11. 不破坏状态模型不变量

新交互**不改变** [`permission-grant-state-model.md`](./permission-grant-state-model.md) 的任何不变量，仅改变触发方式：
- 单元格切换仍走 `commitGrantTask`（grant/adjust/remove intent），只是触发器从"弹窗确认"变为"点击"。
- 批量仍产 1 个 `GrantTaskSnapshot`（多操作×多资源），只是从"弹窗四步"变为"矩阵多选+工具栏"。
- 条件/canGrant 就地展开仍写同一任务快照。
- 子权限矩阵展开用 `child-grant`/`child-update`/`child-remove` 逐命令语义（T-FE-033 修订，替代旧 `TaskChildGroup` 完整集合替换）。
- 保存仍走 `saveAll` 两步 + 部分失败处理，新增的 SAVE_PREVIEW 是 `DIRTY->SAVING` 间的 UI 中间态，不新增后端调用。

唯一新增的交互态（INLINE_CONFIG_OPEN / BATCH_SELECTED / CONFLICT_HIGHLIGHT / SAVE_FAILED_MARK / SAVE_PREVIEW）都是 D4/D5 的**正交 UI 子态**，不影响有效态与草稿态的语义。
