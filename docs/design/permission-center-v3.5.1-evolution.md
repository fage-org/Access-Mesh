# 权限中心 v3.5.1+ 演进方向

> 状态：**演进方向（非约束）**。本文记录 v3.5 范围外的后续增量项，供后续专项设计参考，当前不作为实现依据。
> 关联设计：[permission-center-v3.5-design.md](permission-center-v3.5-design.md)（v3.5 当前权威设计，`status: adopted`）

以下内容在 v3.5 PM 决策回退中被移出 v3.5 范围，作为后续增量章节。每项均标注删除来源与当时决策理由；真正纳入实现前需重新评估业务真实需求。

| 运营调控替代路径（原 §8） | 同上 | 实施细节 |
| 迁移计划（原 §10） | 同上 | 实施细节 |
| 兼容性策略（原 §11） | 同上 | 实施细节 |

| 风险与回归监控（原 §14） | 同上 | 待方案稳定 |

## 纳入流程

任一增量项从「演进方向」转为「权威设计」时：

1. 经 PM 评审确认纳入某版本（如 v3.6）；
2. 在 `docs/design/` 新建/更新对应设计文件，`status: adopted`；
3. 若取代本演进文件中某项，将该项从本表移除或标记「已纳入 v3.X，见 <link>」；
4. 触发设计变更依赖扫描（见 skill §4.2），核对相关任务的 `design_refs`。
