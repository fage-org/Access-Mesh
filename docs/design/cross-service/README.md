# 跨服务设计索引

本目录用于存放跨越多个服务边界的当前有效设计。这里的文档属于 `docs/design/` 权威设计的一部分，描述服务之间的职责、契约、数据流和一致性约束。

| 主题 | 文档 | 说明 |
|------|------|------|
| admin-service 与 permission-center 同步 | [admin-permission-sync.md](admin-permission-sync.md) | 用户、组织、菜单等 admin 事实同步到权限中心的任务模型、接口契约、安全边界和全量校准设计 |

本目录文档只面向长期有效的契约、数据流、安全边界和一致性约束，不收录阶段任务、迁移检查或验收清单。阶段性执行计划、核对清单和临时排期不放在本目录；仍在推进的计划放在 `../../plans/`，已完成的过程文档归档到 `../../archive/YYYY-MM-DD/`。

即使主题相同，新一轮执行计划也应另起 `../../plans/<topic>-plan-vN.md` 或更贴近任务名的计划文件；不要把 S9、S10 之类的过程步骤继续追加到本目录的设计文档中。
