# T-GW-011 Gateway 白名单死路由与死配置清理

## 背景

gateway application.yml 白名单含 `/public/**` 与 `/captcha/**`，全三服务控制器（实测 41 个：access-service 39+example-service 2，gateway 为 WebFlux 无控制器类）无任何此前缀——命中白名单的请求跳过鉴权后在网关路由层 404（纯审计噪音）。`unregistered-policy: DENY` 配置与 GatewayProperties 对应字段全仓无消费点（InterfaceAdmissionMatcher 硬编码未注册即 DENY）——死配置，疑似曾计划可配置策略。

## 范围

两行白名单+一个死配置字段删除。

## 当前口径

直接删除不接线（未注册恒 DENY 已是现行契约语义——InterfaceAdmissionMatcher.java:112-115「无注册匹配：拒绝」，无 ALLOW 需求不扩策略面）。

## 验收对照

- [x] 白名单两行删除+快照测试更新
- [x] unregistered-policy 死配置清除
- [x] 构建绿

## 非目标 / 遗留

- 可配置未注册策略：不做。
