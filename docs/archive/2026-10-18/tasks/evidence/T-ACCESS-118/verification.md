## 本地代码轨

主代理在修复后独立只读核对生产 diff、调用链、测试和原外评：

- Gateway 准入、服务层 QueryGate、租户 SQL、分类转授与普通用户默认无权限均未改动；文件长度校验在权限检查后、物理落盘前，不增加读取或免登通道。
- 生成的相对 UUID 路径为本次请求私有值；回滚回调只清该路径，清理复用原路径安全函数与容错逻辑。无独立线程/数据源/重试队列，不覆盖原错误。
- 提交成功不清理；未知状态保留并 WARN；清理失败保留并 WARN。没有把进程内尽力补偿写成数据库/磁盘强原子保证。
- 附件标记由已通过会话归属校核的公共响应回调获取；JSON 附件不解析内容，即使字节看似错误信封也保持文件语义。无附件头的 JSON 业务错误仍拒绝下载。
- 删除发出前仍检查原上下文与权限；发出后只在同会话且页面存活时发起当前筛选的新请求，不把旧响应作为新列表。
- 同类扫描覆盖 `downloadFile` 和 `exportAuditLogs`，重复失败解析已删除；公共 HTTP 仍是非 2xx 会话/错误处理入口。没有引入通用下载框架。
