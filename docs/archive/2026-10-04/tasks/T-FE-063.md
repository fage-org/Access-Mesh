# T-FE-063 前端测试按能力复用与参数表达精简

## 背景

承接[测试精简方案](../../../design/testing-simplification.md#candidates)与[执行计划](../testing-simplification-plan.md)。已完成测试辅助函数精简，消费者契约保持；运行证据见完成记录。

## 范围

1. 以 grant-plan.spec.ts、grant-keys 及候选能力内 spec 为起点，查明已有工厂与参数表；仅处理同一消费者/契约中的重复安排与数据变体。
2. 保留 role/utils/types.spec.ts 与 user/utils/roleAssignCandidates.spec.ts 的不同允许集合；组织树/岗位/API 包装器同样不按小文件配额强行合并。
3. 保留键编码、undefined/null 归一、角色命名空间与碰撞反例，以及前后端独立 golden；使用现有 Vitest 数据表，不默认新增性质测试依赖。

4. 核对 list-load 与页面 hook 的 defer/flush 实际重复，按真实调用方抽取支持函数；保留消费端请求参数、消息和上下文接线差异，不把共享 helper 测试替代消费者证据。

## 当前口径

按[设计的证据取舍](../../../design/testing-simplification.md#evidence-policy)与[验证边界](../../../design/testing-simplification.md#validation)执行，现役硬规则见[测试规范](../../../../.claude/rules/testing-standards.md)。每批改动只维护本批映射；开始前核对 HEAD 增量，不把附件估算或历史通过记录当本次验收。
