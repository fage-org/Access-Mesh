# T-FE-061 停用主体授予入口状态与草稿保护

## 背景

承接 [Q-037](../../../pending-problems.md#q-037)：角色管理页、组织信息卡允许点击停用主体的授予入口，而 SubjectTreePanel 过滤停用主体；授予 hook 的 preset 找不到节点后 resetAll，未经过 confirmDiscardIfDirty——提示「未找到」而非「已停用」，keep-alive 页在途草稿可能丢失。PositionTab 岗位入口已用禁用态和 tooltip 收敛，本项是其余入口的同型收口。

## 范围

角色管理页与组织信息卡的授予入口；preset 失败分支的草稿保护；提示口径。

## 当前口径

角色和组织入口采用 PositionTab 先例的禁用态+tooltip，提示先启用主体；SubjectTreePanel 过滤行为不变。预选目标缺失时先确认放弃草稿，取消则保留原主体与草稿；外部链接无法查明缺失原因时提示「未找到或已停用」，不为区分原因增加查询。该边界于 2026-10-04 确认。

## 非目标 / 遗留

- 树面板对停用主体的展示策略（维持过滤现状）。

## 验收对照

- [x] 角色、组织入口采用禁用按钮与 tooltip，沿用岗位页形态。
- [x] 失效预选先确认放弃草稿；取消保留并回到原主体入口，确认后才清空。
- [x] 旧行为失败证据与前端四项验证通过。
- [x] 入口、提示与草稿保护已回写设计 §1.1。
