## 背景

实施前前端只有固定租户登录，需要承载独立平台运营和真实多租户使用。

## 范围

平台登录与布局、租户运营、账号与审计页面，租户登录和本地会话草稿迁移。

## 当前口径

按[前端身份入口](../../../design/tenant-lifecycle.md#frontend-realms)实施，同一浏览器可分别登录，两种身份登出和过期互不清理。

## 验收对照

- [x] 双身份入口与会话隔离。
- [x] 运营页面真实接口接线。
- [x] 登录、草稿与密码交付。
- [x] DTO 对账、前端验证及设计回写。

## 非目标 / 遗留

不新增独立前端部署项目，不提供租户业务代操作。

## 验收证据

已完成实现、设计回写和本地双轨检查。统一验证结果见[验收记录](evidence/tenant-lifecycle/verification.md)。
