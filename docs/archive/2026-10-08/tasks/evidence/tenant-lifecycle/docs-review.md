## 实证通过项

- schema 为唯一表结构与标准基础种子来源；执行 DDL 本身不创建租户，函数由 Java 开通事务调用。三张独立平台表的归属与无 tenant_id 例外已登记。
- API 总册 §6.4、§7.7、§26 覆盖登录切换、强制改密、账号／租户操作、恢复限制、错误码、审计及未知门禁响应。
- 运营边界明确：平台不进入客户用户／组织／角色／授权管理；首管理员凭据恢复是限定例外，不恢复状态或角色。
- Redis 单主范围、未知状态拒绝、自动修复、重启后原生会话失效，以及受控实例／备份恢复均有运行规程；没有承诺外部离线 JWT 即时撤回或自动主从切换一致性。
- 旧 tenantId 登录、固定 default 编码、自动租户初始化、旧 bootstrap 环境变量的活跃指引已清理；历史基线保留并明确标为实施前事实。
- 任务、计划、看板、设计入口、问题索引与归档引用同批维护；Q-059 的客户内部管理员治理仍保持独立边界。
