## 背景

Gateway 的权限快照不能代替独立的租户生命周期门禁。

## 范围

平台专属入口、租户 Redis 门禁、会话代次和响应语义。

## 当前口径

正常请求不逐次回源数据库；故障与未知状态拒绝。身份清洗、M2M 精确清单及原权限判定不放宽。

## 验收对照

- [x] 独立平台入口与身份混用拒绝。
- [x] 租户即时门禁与故障拒绝。
- [x] 定向验证及 Gateway 设计回写。

## 非目标 / 遗留

跨服务产品旅程由 T-ACCESS-096 在 e2e 模块验收，不在 Gateway 模块增加 E2E 拓扑。

## 验收证据

已完成实现、设计回写和本地双轨检查。统一验证结果见[验收记录](evidence/tenant-lifecycle/verification.md)。
