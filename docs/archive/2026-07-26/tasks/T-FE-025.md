# T-FE-025 权限授予中栏资源权限概览与授权入口

## 目标

在不调整左栏角色树的前提下，把现有 `PermissionMatrixPanel` 从直接编辑矩阵重构为资源权限概览：展示资源层级、当前有效/直接权限摘要和草稿状态，并通过 Hover/Focus 解释权限来源；提供授权入口打开授权弹窗，点击已有权限标记打开调整弹窗。

## 非目标

- 不实现授权弹窗，归 T-FE-026。
- 不实现右栏变更记录，归 T-FE-028。
- 不恢复原设计中栏批量入口（R5 已确认）。
- 不新增后端有效权限接口；能力不足按设计确认结果降级。

## 实现前确认

- [x] R1：前端阶段只展示可证明的直接、条件、ALL 覆盖和草稿；派生/有效来源待 T-PERM-034 完成时核对，不阻塞本任务。
- [x] R2：状态词、操作简称、颜色与可访问文本。（A1 状态词 + B1 色符字三合一 + WCAG AA，见 §16.8 R2）
- [x] R3：操作摘要"+N"的数量、排序和展开规则。（A1 排序 + B1 显示 3 个 + C1 popover，见 §16.8 R3）
- [x] R5：本轮不恢复原设计中栏批量入口；授权弹窗多选属新交互模型（见 §16.4）。
- [x] R6：ALL、直接实例和操作继承的展示优先级。（A1 优先级 + B1 不自动清理 + C1 文案，见 §16.8 R6）
- [x] R7：GROUP_ROLE 维持只读说明，不伪造有效权限摘要；后端能力核对不阻塞本任务。

## 验收标准

以 frontmatter `acceptance` 为准；全部满足并回写设计后才能进入 done。

## 实现记录

### 2026-07-12 实现

- **PermissionMatrixPanel 重构**：el-table tree 两列（资源 + 操作摘要），受控 `expand-row-keys`（row key = `codeType|resourceCode`，ALL 节点 `__ALL__`）；搜索递归过滤树保留祖先路径；移除 toggle 直接编辑与矩阵列循环。
- **新建 PermissionSummaryCell**（`@/components/PermissionSummaryCell`）：窄接口，接收 `SummaryItem[]`；按七类「色+符+字」三合一渲染，默认 3 个 + `+N` popover（含未授权全部剩余），全未授权单个 `·`；tag 为可聚焦 button + `:focus-visible` ring，Popover `trigger=['hover','focus']` 满足 Hover/Focus 等价。
- **摘要正交分解**（`utils/summary.ts`）：`SummaryItem` 拆 effective（主状态）+ draftChange（草稿副状态），解决 ALL 覆盖下移除直接记录的展示；`sortSummary` 按 R3 排序。
- **store 修正**（`hook.ts`）：`buildMainCellContext` 的 `allCovered` 只看 `mainDraft`（计划态：ALL 被草稿移除后实例不再显示 ALL 覆盖，三栏一致），正交于 INSTANCE 直接记录状态；加 `hasBaselineDirectRecord`（baseline 是否有 INSTANCE 直接记录，副标记依据）。
- **事件契约下沉**（`@/utils/permission-grant-types`）：`GrantTriggerPayload` / `AdjustTriggerPayload`（携带 domainCode，draft 快照）；`SummaryItem` / `SummaryEffective` / `SummaryDraftChange` 类型同步下沉（消除共享组件反向依赖页面 utils）。
- **index.vue 清理**：移除 `AdditionalSettingDialog` + 子权限 `el-drawer` + `child-binding` adapter + 相关状态/处理函数；`open-grant`/`open-adjust` 占位接收（info message）。
- **删除文件**：`AdditionalSettingDialog.vue`、`utils/child-binding.ts`。
- **派生权限**：渲染能力保留（DERIVED/⊕），normalizer 不产生（R1/R7 待 T-PERM-034）；GROUP_ROLE 只读 alert 保留。
- **验证**：pnpm build / typecheck / lint 全过。
