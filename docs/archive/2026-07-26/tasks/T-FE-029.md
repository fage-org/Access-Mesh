# T-FE-029 权限授予V2页面骨架+路由+三栏+角色树+能力门控

## 目标

搭建 V2 页面骨架与独立路由，复用角色树数据适配与能力门控逻辑，不动旧页面。

## 非目标

- 不实现矩阵编辑与单元格摘要（T-FE-031）。
- 不实现方案 A 新模型（T-FE-030）。
- 不新增后端接口。

## 实现要点

- 路由模块 `router/modules/` 新增 V2 路由项；菜单可选登记。
- **V2 mock 隔离（dev-only transport 注入）**：V2 页面通过 `useV2GrantTransport()` 获取 transport 接口发请求，**不**经全局 http client，避免旧 mock 对 canonical URL（`/api/perm/role-resource-permission/*` 等）的路由接管。dev：transport = 内存 mock 骨架 + 基础单分支 fixture（多条件分支/失败模拟归 T-FE-035 扩展），不注册 fake route 到全局 mock 路由表；prod：transport = 标准 http client，走真实后端 canonical URL。环境判定用 `VITE_ENABLE_PROD_MOCK`（与 `build/plugins.ts` fake-server `enableProd` 同源）：dev 服务或演示构建（开关 `true`）-> 内存 transport（不经全局 http client，绕开 fake-server 接管）；真实部署构建（开关 `false`）-> 标准 http client。`.env.production`/`.env.staging` 默认 `false`，`.env.demo` + `pnpm build:demo` 显式 `true`。只读端点（abstract-role/tree、type-definition/list、resource-entity/tree、operation-permission/list、permission-condition/list）**全部走共享 API**，结构差异在 V2 侧做本地适配，**不**改走 V2 transport（避免第二事实源）；`useV2GrantTransport()` 仅承载可变授权 `role-resource-permission/*`。旧页面 mock 不动。
- 角色树可复用旧页面 `RoleTreePanel` 的数据适配函数，但组件独立（避免反向依赖旧页面）。
- 能力门禁沿用 `ROLE:VIEW` / `ROLE:MANAGE` + `operatorCapability`（fail-closed）。
