# Access-Mesh 测试：最小充分证据

目标是以更少的重复维护守住当前契约，而不是降低测试数量、覆盖率或把所有场景塞进少数文件。评审可得出“不新增／不修改测试”。按用户实际请求确定操作范围：制定计划允许编写计划，评审结论核实并修复允许明确修正；纯评估不自动授权测试重构或技能安装。已明确要求按计划执行时，继续必要实施，不重复索取授权；产品支持变更及真实存疑取舍仍须明确决定。

## 先定位权威和本次范围

从仓库根读取 [AGENTS](../../../AGENTS.md)、[测试规则](../../../.claude/rules/testing-standards.md) 及命中的领域规则；只读本次相关设计、生产代码、测试与实际运行配置，不全文扫描历史任务。测试硬约束以仓库当前权威为准，本技能负责处置流程。冲突须明确指出，不能静默选择宽松口径；已获准实施范围内的明确动作不反复索取确认。

不要将文件后缀、旧任务编号或历史通过数当成当前轨道和支持承诺。旧版本迁移、幂等、回滚等只按当前明确支持范围判断；空库初始化也不豁免原样 DDL、种子、约束和实际承诺的初始化行为。

## 日常流程

1. **找已有证据。** 明确本次行为／风险、触发条件、预期结果与关键禁止副作用，搜索相关低层、接线层和跨层测试。
2. **先复用再新增。** 已有证据充分则不新增；缺数据变体先考虑现有参数表；缺独有失败信号才新增案例；确有新能力或隔离边界才新增文件／昂贵上下文。
3. **选择最低且可信的层。** 纯逻辑与依赖交互放低层；原样 SQL、DDL、真实事务和持久化语义用 PG；HTTP／UI／E2E 只承担各自接线与用户行为风险。最低层不能可靠暴露问题时不得强行下移。
4. **小批次验证。** 先相关案例，再受影响轨道；范围较大的精简最后按仓库收口要求回归。只使用核实过的命令，不把 skip、未发现或编译成功当成行为通过。

## 怎样合并和删除

先区分：独有有效证据、语义重复、无契约价值的偶然实现约束、已退出支持的场景。独有证据先迁移并验证；重复证据给出接替位置；偶然实现约束说明为何可移除；退出场景核对支持依据与活跃引用。旧 bug 已修复、名称相似、覆盖相同代码行，都不是独有回归可删的理由。

同结构的数据变体可参数化，每行有明确名称、独立前置条件和可定位断言。安全身份、租户、拒绝原因、烧码／重放、条件与副作用边界不得被隐藏。需要大量条件分支才能统一的案例保留拆分；小文件无须仅为减少文件数合并。

保留**当前有效行为与稳定架构契约的证据并集**，不机械保留原 assert 字面形式。多个互补断言可以证明同一次操作；多个独立操作不要串成前一个失败就遮蔽后续案例的巨型测试。明确的有序业务旅程保持整体隔离，不与无关单测混合。

共享工厂只减少重复安排，不隐藏被测动作、身份来源和核心断言，不重写一套业务算法作为 oracle。参数对象、mock、数据库数据和清理默认按场景独立；别创建带大量开关的万能测试框架。

## 项目证据边界

- mock 调用阻断不能替代真实 PG 事务回滚；PG 结果断言也未必证明被禁止的下游从未调用。稳定锁序、入口约束与禁止副作用不是应一律删除的实现细节。
- H2 不能证明 PG 特有语义，但不因此删除全部 H2 测试。当前 schema 校验已采纳 PG-only（[设计](../../../docs/design/testing-simplification.md#candidates)）：非容器轨不证明 DDL 正确，DDL 改动必须定向 PG 实跑。其他 H2 上下文保持；非数据库行为留在合适低层。关键替代实际运行前不删原证据。
- 前后端不同实现的 GoldenFixture 可提供独立证据；不能因数据相同只保留一端。退役路由须有真实注册缺失或等效路由证据，401／403 不足以证明路由不存在。
- 复用当前 ItInfra、E2E 支持设施与隔离策略，不随手共享 Spring 上下文、合并 H2／PG execution 或开启线程并行。确需调整时单独证明状态安全和授权范围。

## 精简任务的额外检查

涉及删除、跨层替代、数据库证据迁移或成组重构时，读取 [精简检查表](references/simplification-review.md)。映射只覆盖本次受影响项并随提交归档，不建设长期全仓测试台账。高风险替代按需检查具体回归信号；不要求普通重命名都运行 mutation 测试，不把工具分数当删除许可。

## 交付

说明处置和理由、保留／迁移的证据、未解决风险。报告实际命令和范围，分别标注 `passed / failed / skipped / not run`；区分静态审查、结构校验与行为执行。计数区分文件、声明、展开案例、skip、上下文／容器启动与耗时，不承诺未测收益。环境不足时停在证据边界，不修改 CI 或禁用测试来获得绿色。

只有获准安装或更新技能时，才按 `AGENTS.md` 同步 `.claude/skills/` 与 `.agents/skills/` 的对应目录并更新入口；本技能不自行授予安装权限。
