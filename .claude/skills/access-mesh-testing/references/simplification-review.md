# 测试精简检查表

仅在删除、跨层替代、数据库证据迁移或成组重构时读取。日常新增测试使用主 SKILL 即可。本表提供流程，不改变仓库当前测试硬约束。

## 1. 本批最小映射

只列本次受影响的案例或一组同结构参数，不登记全仓清单。

| 原案例／参数组 | 当前契约与可区分错误 | 处置 | 接替位置或退出依据 | 验证状态 |
|---|---|---|---|---|
| 类／方法／case 标签 | 前置条件、结果、关键禁止副作用 | 保留／参数化／迁移／删重复／删无效／退出支持 | 明确到保留 case／assert；无效项解释为何非契约 | passed / failed / skipped / not run |

“有效”包括行为、对外格式与稳定架构／安全约束，不包括只因过去实现恰好如此而固化的细节。无法判断时列为待决，不猜测可删。需要改变支持范围或现行规范的项目单列，不用删测暗中完成产品决策。

## 2. 删除引用闭包

在当前提交搜索拟删类名、方法选择器、fixture 和脚本名，同时检查测试发现配置、任务脚本、CI、活跃运行手册与相关测试辅助代码。不要只在与候选同目录的文件中搜索。

区分仍执行的引用与仅历史追溯的引用。历史文档可以保留并标历史，不为追求零搜索命中删除全部档案；仍被测试或受支持命令读取的资产，必须先迁移消费者或调整当前支持入口。

**混合测试按证据拆分。** 例如“旧库迁移后发布成功”同时包含升级兼容、当前发布、无授权种子时不得凭空授予权限等不同主张。升级退出不自动授权删除当前业务断言。迁入已有类后重审 fixture 范围，不能照搬依赖全库为空的计数断言。

## 3. 等价与诊断检查

比较相同的支持契约、输入、身份／租户、初始状态、故障注入点、观察边界、错误码／原因、禁止副作用及清理。参数化必须逐行可识别；仅返回值相同不足以判为重复。

结构合并通常减少声明，不减少展开执行。删除语义重复才可能减少执行；删除容器测试不等于同数量的容器启动消失。计算净维护成本时，包含新 helper、数据表、间接调用和参数传递开销。

SQL 字符串、私有调用或文件数量断言先确认是否保护明确架构规则。语义断言迁入真实运行层后，仍需覆盖独立的结构约束；不能把静态文本出现当作数据库行为已验证。

## 4. 高风险回归信号验证

高风险包括安全边界、真实事务、并发／缓存、PG 替代 H2 独有证据，以及对等价性存在争议的删除。

选少量与本批直接相关的临时错误变体，先备份并确保最终恢复；遵守 Maven 运行期间不改源码纪律。检查旧证据和保留证据分别能否发现同一个实际错误，最终恢复生产代码。以目标行为断言失败为有效发现；编译失败、环境失败、超时与未发现测试不计入。

PIT／性质测试只是可选辅助手段，采用前核对实际 JDK、JUnit、插件与依赖版本。保持输入、配置和变异集合可比；总分相同或杀死相同的一小批 mutants 不证明完全等价。SQL、并发和安全领域错误可能需要定向故障注入。性质必须来自产品契约，不照搬“权限单调”等可能与互斥语义冲突的假设。

## 5. 运行与停止条件

先验证直接相关案例和受影响轨道，再按当前收口规则回归。保留实际命令、发现／执行／skip 情况与隔离条件；双 execution 的空匹配容忍不能被解释成目标类已经执行。性能比较区分冷／热缓存及并行 wall time，不把各 testcase duration 直接相加当总耗时。

出现独有证据无落点、关键轨被跳过、参数化隐藏条件、状态污染、新 flaky、悬空引用或授权越界，暂停本批并修复或回退。不要降低现有门槛、改 timeout 掩盖问题或擅自禁测。

## 6. 技能本身的行为验收题

以下是建议题目与期望，不是自动执行记录；获准安装后用实际 agent 试用。

| 输入任务 | 合格行为 |
|---|---|
| “新增一个已经由现有测试覆盖的空值测试” | 找到已有证据；没有实际缺口就不新增。 |
| “把两个不同能力的小前端 spec 合并” | 核对消费者与契约；允许建议保留分文件，而不是追求文件数下降。 |
| “退出历史迁移并删除共享 fixture” | 找出跨目录消费者，拆分历史与当前断言，完成活跃引用闭包。 |
| “PG 回滚测试太慢，改成 Mockito” | 说明证据不等价，保留真实回滚验证。 |
| “删除低价值的连接工厂非空断言” | 判断是否已被同边界真实行为蕴含，不机械要求再写一个替代非空断言。 |
| “两个类覆盖同样源码行，删一个” | 不接受覆盖重叠作为充分依据，核对故障信号与禁止副作用。 |
| “所有 PG 类统一继承一个动态属性方法提速” | 识别上下文／数据库／全局状态隔离变化，要求单独验证，不直接套用。 |
| “Docker 不可用，但 Maven 退出 0” | 报告相关轨 skipped 或 not run，不宣称全量通过。 |
